# AI 学习平台

> 面向理工科大学生的**本地优先（Local-first）AI 学习平台**

把你自己的课程资料（PDF、Word、PPT、图片）导入进来，由你自己配置的 AI 把它整理成结构化知识，
再通过问答式 AI 导师、自适应测验和错题本来学习。

课程资料与学习数据默认保存在本机浏览器中；AI 服务由你自行配置。

**当前版本：V0.2.5（0.2.5）**

## 项目简介

这是一个**给自己用的**大学课程学习工具，尤其适合数学、物理、计算机、统计等理工科课程。

它解决的核心问题是：**课程资料很多，但没人陪你把它们真正弄懂。**

传统做法是"看 PDF → 看不懂 → 放弃"。这个项目把流程变成：

```text
导入课程资料
    ↓
AI 提取结构化知识（主题 / 概念 / 公式 / 符号 / 例题 / 习题）
    ↓
AI 导师用提问的方式带你学（不是直接把答案倒给你）
    ↓
做测验 → 错题自动进错题本 → AI 分析你错在哪 → 针对性再练
```

几个设计上的取舍：

- **本地优先**：课程文件、学习记录、错题本都在你自己的浏览器里，不上传到任何服务器。
- **自带 AI**：项目不提供 AI 服务，你自己填 API Key。用哪家、用哪个模型由你决定。
- **本地解析**：PDF 解析、OCR、分块全部在浏览器本地完成，只有"分析"和"提问"才会调用 AI。
- **不评判你**：错题分析只陈述可观察到的模式（如"符号处理"、"概念理解"），**永远不会**给你贴"粗心"这种标签。

## 核心功能

### 课程资料管理

- 支持格式：**PDF、DOCX、PPTX、图片（PNG / JPG / WebP / GIF / BMP）、粘贴文本**
- **批量上传**：一次可选多个文件，每个文件生成一份独立文档（最多 50 个/批，并发处理 2 个）
- 上传后自动在**本地**完成：文本提取 → 结构识别 → 语义分块
- 图片走**本地 OCR**（tesseract.js），不联网
- 每个分块都保留来源引用，例如 `Calculus.pdf · Page 12 · § 导数`
- 重复文件会被识别并跳过，不会静默创建重复文档

### AI 课程分析

- 一次性提取：**主题、概念、公式、符号、例题、习题、先修知识**
- 符号会记录"上下文"，因此同一个符号在不同主题下可以有不同的含义
- 采用**流式请求**，长课程分析不会因为固定超时而中断
- 分析失败时会明确告诉你原因（如"输出被截断"、"API 密钥无效"），并保留已提取的文档与文本

### AI 导师（AI Tutor）

问答式学习，而不是直接给答案：

```text
简短讲解 → 提问 → 你作答 → 评价 → 反馈 → 渐进提示 → 下一题
```

- 回答基于你的课程资料；超出资料范围的内容会明确标注为"补充说明"
- 提供**渐进提示**（逐步给，不直接给答案）
- 每次会话都保存在本地，可在"对话记录"里回看

### 公式与符号

- 从课程资料中提取的**公式**（KaTeX 渲染）与**符号**集中展示
- 支持搜索，点击即可复制
- 同一个符号的不同含义会作为独立条目保留

### 划词翻译

- 在页面中**选中任意文字**即可弹出翻译
- 会带上上下文段落，让翻译更准确
- 翻译目标语言跟随你的设置（中文 / 英文）

### 测验（Quiz）

- 从课程分析结果生成题目，**题目有据可依**（来自你的资料）
- 五种题型见下方"支持的测验题型"
- 支持：主题选择、题目数量、起始难度、题型组合
- 答题后可查看解析、参考答案与"再来一组"（同主题 / 相似 / 更难 / 更简单 / 薄弱点强化）

### 错题本

- 答错的题目**自动收集**，同一道题多次答错会合并
- 由 AI 分析：**从哪一步开始偏、关键错误是什么、为什么这一步不成立、正确思路**
- 错题可标记为"已掌握"或归档
- 提供**薄弱点提示**（"可能需要复习的部分"）

### 自适应练习与掌握度

- 难度根据近期正确率、连对/连错、知识点掌握度动态调整
- 掌握度是**基于练习记录的估计值**，不是对能力的绝对测量
- 提供知识点维度的掌握度视图（最薄弱的排在前面）

### 本地优先数据存储

- 所有数据存于浏览器 **IndexedDB**（Dexie，33 张表，schema v11）
- 课程原始文件字节同样保存在本地
- 无需后端、无需注册账号、无遥测
- 首次启动会预置两个演示邀请码（见下方"首次使用"）

## 支持的测验题型

| 题型 | 说明 |
| --- | --- |
| **单项选择题** | 4 个选项，选择一个 |
| **判断题** | 正确 / 错误 |
| **数值题** | 输入数值，按容差比较 |
| **数学表达式题** | 输入表达式，按数学等价判断（如 `x^2/2` 与 `0.5x^2` 视为等价） |

> **说明：简答题不包含在本版本中。** 简答题无法可靠地自动判分，为避免给出错误的判定，
> 该题型已移除。

数学等价判断使用 `mathjs`：先尝试符号化简，再用数值采样验证，因此**不依赖 AI 判分**，
结果可复现。无法确定时会明确显示"无法自动判定"，而不是猜测对错。

## AI 配置

**本项目不提供 AI 服务，也不会内置任何 API Key。** 你需要配置自己的 AI API。

启动后进入：

```text
设置 → AI 设置
```

填写：

| 项 | 说明 |
| --- | --- |
| AI 服务商 | 选择预设或"自定义（OpenAI 兼容）" |
| API Base URL | 服务商接口地址 |
| API Key | 你自己的密钥 |
| 模型 | 模型名称 |
| 温度 / 最大 Token 数 | 采样参数 |

内置预设（均为 **OpenAI 兼容接口**）：

```text
OpenAI
Qwen（DashScope）
DeepSeek
MiniMax
MiMo
自定义（任意 OpenAI 兼容端点）
```

配置完成后可点「测试连接」验证。API Key 会以 **AES-GCM 加密**保存在本地（密钥为不可导出的设备密钥），
不会写入日志、不会放进 URL、不会提交到本仓库。

> 也可以直接改用任何兼容 `/chat/completions` 的服务。

## 安装与运行

### 环境要求

- **Node.js 20 或更高版本**（写在 `package.json` 的 `engines` 中）
- 现代浏览器（Chrome / Edge / Firefox / Safari）

### 快速启动（推荐）

项目自带启动器，会替你检查运行环境。

**Windows**：双击项目根目录下的 **`Start.bat`**

**macOS / Linux**：

```bash
./launcher/unix.sh
```

启动器的流程：

```text
1. 检测 Node.js 是否存在、版本是否满足要求
2. 检测 npm 是否可用
3. 缺少或版本过低 → 提示 → 等你确认 → 才尝试安装
4. 安装完成后重新检测
5. 检查依赖是否完整（必要时安装）
6. 启动开发服务器并打开浏览器
```

已经装好 Node.js 的用户**不会被重复安装**，启动器会直接进入启动流程。

> **关于安装 Node.js**：启动器不会静默安装，也不会绕过系统权限。
> Windows 使用 `winget`；macOS 使用 Homebrew；Linux 按发行版使用 `apt` / `dnf` / `pacman` / `zypper`。
> 如果这些工具不存在，启动器会给出 [Node.js 官方下载页面](https://nodejs.org/zh-cn/download)，由你手动安装。
>
> 详见 [launcher/README.md](launcher/README.md)

### 手动启动

不想用启动器，或本机已有符合要求的 Node.js：

```bash
git clone <仓库地址>
cd website
npm install
npm run dev
```

然后打开 **http://localhost:5173**

> **重要**：应用数据（项目、文档、AI 配置）保存在浏览器的 IndexedDB 中，而 IndexedDB 是**按来源（origin）隔离**的。
> 请始终使用**同一个地址**（`http://localhost:5173`）。
> 不要使用 Vite 打印的 `Network` 地址，也不要让端口变成 5174/5175 —— 那会被浏览器视为另一个网站，
> 你会看到一个"空的工作区"。项目已固定端口（`strictPort`）以避免这个问题。

### 首次使用

首次启动会预置两个演示邀请码：

| 邀请码 |
| --- |
| `WELCOME-LEARN` |
| `STUDENT-2026` |

邀请码**仅在本地校验**，它是一个本地应用的访问门，不是账号系统。

### 生产构建

```bash
npm run build     # 输出到 dist/
npm run preview   # 本地预览构建结果
```

## 使用流程

```text
1. 创建项目（选择科目，如"微积分"）
2. 在「文档」标签页上传课程资料（可批量）

```

在配置 AI 之前，上传与本地处理都可以正常使用；只有分析、导师、测验生成等需要 AI。

## 数据与隐私

- 本项目采用 **Local-first** 设计：课程文件、分块、学习记录、错题本、AI 设置都保存在**本机浏览器**中。
- 本仓库**不包含**任何用户课程资料、个人 API Key 或学习数据。
- PDF 解析、OCR、分块等处理**在本地完成**，不联网。
- 当你配置了 AI API 后，**相关内容会发送给你所配置的 AI 服务商**：
  - 课程分析：会发送用于分析的分块文本
  - 导师提问 / 测验生成：会发送相关片段与你的作答
  - 划词翻译：会发送选中的文本与上下文段落
  - 请求**只包含完成任务所必需的内容**，不会发送你的整个文档库
- 数据是否被服务商留存、如何使用，**取决于你所选择的 AI 服务商及其政策**，本项目无法控制。
- API Key 以 **AES-GCM** 加密存储，密钥为不可导出的设备密钥。

> 换句话说：**在你不使用 AI 功能时，数据不离开本机；一旦调用 AI，相关片段会发送到你自己配置的服务商。**

## V0.2.5 更新

### 课程内容持久化与 freshness

AI 分析结果本来就在本地数据库里，这一版把「**打开课程绝不重新分析**」从约定变成了可验证的机制。

- **新增课程内容层**：`CourseContentRepository` / `CourseContentService` 是课程分析结果的**统一只读聚合 + 新鲜度 + manifest** 逻辑层。它不拥有任何表、不复制数据、不新建第二套存储。
- **内容指纹 `sourceHash`**：由参与分析的 chunk **内容**（文本 / 顺序 / 页码 / 章节）计算，**不含 `processedAt`、不含 chunk id**。因此「原样重新处理」不会误判为内容变化，只有文本真的变了才算变。
- **四个版本概念分离**：Dexie 结构版本 / `promptVersion` / 分析结果形状 `schemaVersion` / 教材结构 `version` + `structureHash`。不再合并成一个字段。
- **新鲜度判定**（纯函数）：`sourceHash`、`promptVersion`、`schemaVersion`、结构指纹（优先 `structureHash`，旧数据回退 `version`）、`status`。**明暗模式、配色主题、界面语言、课堂进度、练习记录都不参与。**
- **原子替换**：重新分析改为单事务写入 —— 要么新结果完整落库，要么旧结果原样保留。**AI 失败时旧分析不受影响。**
- **上传后自动分析**：处理流程结束后按需触发一次，并做并发去重（同一项目同时只发一次请求）。**打开任何页面都不会触发分析。**
- **未配置 API Key 是 `no-provider`**，不是「分析失败」。
- 修复 `promptVersion` 被硬编码为 `v1` 的问题；修复用户资料并发写入时的丢更新。
- **增量分析在 V0.2.5 只到规划层**：`AnalysisScope`、`detectAffectedStructure`、`planIncrementalUpdate`、`planContentDependencies` 已就绪并有测试，但**真正的章节级增量生成尚未实现**；按章节请求会被明确拒绝（`ANALYSIS_SCOPE_UNSUPPORTED`），不会静默跑全项目。原因：Topic 可以跨章节，贸然按章节删除重建会破坏 Topic / 笔记 / 文字稿 / 练习题的既有绑定。**章节级增量生成已在工作区实现（Phase 7d，未发布），见上方“工作区”说明。**

### 配色主题（Color Themes）

新增 3 套配色，与明暗模式是**两个独立维度**（`Light/Dark/System` 决定明暗，`Color Theme` 决定色系）：

| 配色 | 说明 |
| --- | --- |
| **Default** | 网站原有中性配色，保持不变 |
| **Pink Aqua** | 柔和粉色 + 清爽水蓝 |
| **Warm Orange** | 暖橙与酒红，偏笔记 / 书籍感 |
| **Academic** | 绿、蓝、黄，接近大学教材 |

- **主页新增 Appearance 选择器**：Mode（浅色 / 深色 / 跟随系统）+ 4 张配色卡片，卡片上显示**真实色点预览**，可一眼看出区别。
- 每套配色都有**独立的浅色与深色变量块**，深色不是简单套用同一套色，而是重新调过饱和度与亮度，避免刺眼。
- 配色持久化在**用户资料**里（不新增 localStorage key），刷新后保持。
- 颜色定义集中在 `colorThemes.ts` + `globals.css`，**组件不硬编码颜色**。
- 主页使用克制的主题渐变；**导师阅读区保持纯色背景**，不影响长文可读性。
- **语义色优先**：成功 / 错误 / 警告 / 信息仍使用原有语义色，不会被主题覆盖。
- 切换主题是纯外观行为：**不触发 AI、不使课程分析 / 课时缓存 / 课程上下文失效**。

### 可访问性

- 新增 `--primary-strong`：**填色且承载文字**的表面（主按钮、徽章、Tooltip、品牌标记）改用对比度达标的色值，`--primary` 继续用于图标、链接、进度条、柔和状态与 focus ring。

| 配色 | 浅色主按钮 | 对比度 |
| --- | --- | --- |
| Pink Aqua | `#1E8F9C` | 3.84:1（原 3.24:1） |
| Warm Orange | `#8C3332` | 7.79:1（原 3.97:1） |
| Academic / Default | 原色已达标 | 4.82:1 / 15.55:1 |

- 新增对比度测试：从**真实 CSS 变量**解析并计算 8 个「明暗 × 配色」组合的 WCAG 对比度，正文类文字断言 ≥4.5:1。
- Pink Aqua 浅色主按钮仍为 **AA-large（3.84:1）**，未达 AA-normal —— 因为 `#1E8F9C` 是指定色值，达标需要改色。
- `#4C1A2` 不是合法 CSS hex：**逐字保留**在配色元数据中，**不写入任何 CSS 变量**，选择器把它渲染成「不可用」虚线色块，不伪造颜色。
- 已用**真实 Chromium** 验证：4 个视口（375 / 768 / 1024 / 1440）× 8 个组合**无横向溢出**；跟随系统模式下切换操作系统明暗时，配色主题保持不变。

## V0.2.4 更新

### 学习资料：四种角色

上传入口按角色拆分，AI 对四者的使用方式完全不同：

| 入口 | 角色 |
| --- | --- |
| **教材 / 课程资料** | 课程事实的主要来源（课程分析只用它） |
| **我的笔记** | 学习者的补充上下文（可能出错，不覆盖教材） |
| **教授课堂文字稿** | 教授怎么讲 + 课堂进度 |
| **教授练习题** | 教授怎么出题（评估风格） |

- **教授练习题**：上传后自动切分题目、保留 A/B/C/D 选项、匹配答案键，可在线作答并即时判分（复用测验的数学判分器）。
- **教授出题风格**：从真实导入的题目统计（题型分布、计算 vs 概念、选项数量、常见指令），并标注样本量与置信度；生成测验时会参考该风格，且明确**不得复制原题**。

### 课程结构树（章节层级）

- 从教材自身的编号与标题识别 **Chapter / Section / Subsection**（也支持 Unit / Part，保留原文名称），不使用 AI 凭空改写目录。
- 结构使用**稳定 ID**：重新分析同一本教材不会重建章节 ID，笔记 / 文字稿 / 练习题的关联不会丢失。
- 每个内容块绑定 `chapterId / sectionId / chapterNumber / sectionTitle`，**不跨章合并**；页码随章节保留。
- 无法识别章节时不伪造目录，标记为「通用课程资料（低置信）」。
- Topic 会带上所属章节；Topic 页可按教材目录点选章节过滤主题。

### 阅读辅助与稳定性

- **划词提问（Ask AI / Explain）**：在课时页选中文字即可提问，携带选区与上下文，独立于翻译与交互导师。
- **原始视觉保留**：PDF 中的图、表、公式图片在 OCR 不可靠时保留原始图片/页面截图，不把错误 OCR 当正文。
- **`<think>` 推理隐藏**：模型返回的内部推理在进入渲染前被移除，含流式跨分片与未闭合情况。
- **课堂 / 学习 / 练习进度分离**，不合并成一个百分比。

## V0.2.1 更新

### 导师：阅读与练习分离

- **课时页（Topic Tutor）与交互导师（Interactive Tutor）彻底分离**：课时页是**阅读材料**，一次生成、本地缓存、按语言分版，
  再次打开或刷新浏览器都不会重新调用 AI；提问、作答、提示、纠错、难度调整全部在独立的交互导师页面完成
- **课时缓存**：`TutorLesson` 按 `projectId + topicId + language` 存储，用主题指纹（`contentHash` + prompt 版本）判断是否过期；
  课程重析或 prompt 升级才会失效重生成。生成失败时保留并继续显示旧版本
- **并发去重**：同一课时的并发请求合并为一次 AI 调用（React StrictMode / 重挂载 / 快速切换主题都不会重复计费）
- **课时页不再有互动式结尾**：以「Ready to practice? → Open Interactive Tutor」进入练习

### 公式与符号

- **公式与符号面板**：从课时正文中**实际出现的 LaTeX** 提取符号并去重，不额外调用 AI；符号由 KaTeX 渲染，点击可复制
- **数学字符规范化**：新增数学上下文感知的归一化 —— 恢复 PDF 字体缺失 ToUnicode 时产生的 **Private Use Area** 字符
  （复用 Adobe Symbol 编码表），把 Unicode 数学符号统一为 LaTeX（`∩ → \cap`、`△ → \triangle`、`√ → \sqrt{}` 等）；
  无法恢复的字符用明确的 `[?]` 标记而不是删除或猜测
- **代码块与普通文本不受影响**：归一化只作用于真正的数学上下文，跳过 fenced/inline code
- **AI 提示词加固**：要求数学一律用 LaTeX，不得复制源文档中的损坏字符；语义优先于 glyph 外观
  （集合对称差用 `\triangle`，集合差用 `\setminus`）

### 阅读排版（交互导师）

- 正文提升到 **17px / 行高 1.8**，段落间距加大，阅读栏宽限制在约 768px
- 讲解内容通过共享阅读渲染器渲染：Markdown 标题、列表、公式正常排版，而不是一堵纯文本

## V0.2 更新

### 原文阅读体验

- **课程原文阅读器（SourceReader）**：查看原文不再是一个堆满元数据的弹窗，而是一个真正的阅读界面 ——
  正文居中限宽（约 736px）、行高 1.75；文档名与页码作为标题；Chunk ID / Document ID 等**技术信息默认折叠**在"技术详情"里
- **来源引用卡片（SourceQuote）**：测验、错题本统一使用。默认只显示约 320 字符（在句子边界截断），
  可"展开 / 收起"；提供"阅读原文"（打开阅读器）与"打开文档"（跳转到对应文档）
- **分块预览重做（ChunkPreview）**：不再像数据库记录。文档名 / 页码 / 章节在上，正文按阅读排版呈现，
  超长分块可展开，技术字段折叠
- **数学公式排版**：引入 **KaTeX**（随构建打包，完全离线）。`$…$`、`$$…$$`、`\(…\)`、`\[…\]` 正常排版；
  公式过宽时**只在公式块内**横向滚动，不会撑破页面。无法解析的公式原样显示 LaTeX 源码，而不是显示成乱码
- **不误伤正文**：正文按空行分段；**不解释 Markdown**（PDF 里的 `*`、`#` 是内容而不是格式）；
  中英文混排、LaTeX、CJK 正常换行
- **深色 / 浅色主题**：正文使用完整对比度，层级靠字号与颜色区分，**不使用低透明度文字**

### 稳定性与正确性

- **AI 导师"导师不可用 / AI 没有返回可用的题目"**：根因是 `beginTopic()` 把"能否出题"当成了"能否开课"的前提。
  现在**讲解与出题完全解耦** —— 只要讲解生成成功就能进入课程；出题失败只显示一条可重试的提示，
  不会再丢掉已经生成的讲解
- **导师不再依赖测验**：架构上 `TutorService` 不再引用测验服务，一方失败不会拖垮另一方
- **导师取用课程原文更准确**：改为优先按主题自己的 `sourceRefs` 取材料（精确分块 → 引用原文匹配 → 页码 → 文档开头），
  全部落空才回退到项目文档；主题描述也不再丢失
- **导师错误提示更准确**：区分"无法连接 / 响应超时 / 返回为空 / 主题没有课程内容 / 数据无法解析"，
  不再把所有失败都报成同一句话
- **PDF 异常字符排查**（`\uF0C8`、`\uF0C6`、`�`、`?` 等）：定位为 **pdf.js 对缺少 Unicode 映射的字体合成私用区码点**。
  新增检测与安全规范化：**保留原字符并明确告知用户**（文档上显示提示），**绝不猜测替换**；
  仅清理无意义的控制字符。数学符号、CJK、LaTeX 一律不动
- **测验题目出处**：`SourceReference` 增加 `chunkId`，出处引用必须来自**真实分块**；
  无法核实的内容会回退到真实原文，杜绝 AI 编造引用

### 界面

- **长文件名 / 长文本溢出统一处理**：文件名在界面上以省略号显示（保留扩展名），
  完整名称通过悬停提示与无障碍标签提供；卡片、列表、对话框、移动端都不再被撑破
- **数学与符号字体回退**：字体栈补充数学 / 符号字体，避免 `√ ∞ ∑ ∫ ∂ ≤ ≥ ≠ ≈ → ∈ ∪ ∩` 与希腊字母显示成方框

### 启动器

- **Node.js 运行环境检测与安装引导**：启动前自动检查运行环境；缺少 Node.js 时先征求确认再安装，
  版本不满足 `engines` 要求时提示升级，安装后重新检测（Windows 用 winget，macOS 用 Homebrew，
  Linux 按发行版选择包管理器），**绝不静默安装**
- **依赖与端口检查**：`node_modules` 缺失或过期时自动安装；端口被占用时给出处理方案

## 已知限制

- **需要自备 AI API**：不配置 API Key 时，AI 相关功能不可用（上传与本地处理仍可用）。
- **数据绑定浏览器**：清除站点数据 / 更换浏览器 / 更换访问地址，都会导致看不到原有数据。请使用同一地址，并定期用「数据管理 → 导出数据」备份。
- **数学等价判断有边界**：极复杂的表达式可能返回"无法自动判定"，此时该题不计入成绩，而不会算作答错。
- **OCR 质量取决于图片清晰度**：低置信度会给出提示。
- **课程分析为项目级**：一次分析覆盖该项目下所有已处理文档，生成的是课程级知识结构，而非逐文档结果。工作区中的章节级增量分析（Phase 7d，未发布）可只更新受影响的主题。
- **数学可视化范围受控**：只绘制白名单内的显式二维函数；隐式曲线（如 `x²+y²=r²`）、参数曲线、极坐标、分段函数、`tan`/`sec`/`csc`/`cot`、3D、向量、几何与动画均不支持，会安全回退为普通 LaTeX，不生成猜测图形。
