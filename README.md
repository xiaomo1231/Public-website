# AI 学习平台

> 面向理工科与医学大学生的**本地优先（Local-first）AI 学习平台**

把你自己的课程资料（PDF、Word、PPT、图片）导入进来，由你自己配置的 AI 把它整理成结构化知识，
再通过问答式 AI 导师、自适应测验和错题本来学习。

课程资料与学习数据默认保存在本机浏览器中；AI 服务由你自行配置。

## 项目简介

这是一个**给自己用的**大学课程学习工具，尤其适合数学、物理、化学、生物、计算机、统计等理工科课程，以及临床医学与口腔医学大一大二的基础课（解剖、组织胚胎、生理、生化、药理基础、口腔解剖生理）。

它解决的核心问题是：**课程资料很多，但没人陪你把它们真正弄懂。**

传统做法是"看 PDF → 看不懂 → 放弃"。这个项目把流程变成：

```text
导入课程资料
    ↓
AI 提取结构化知识（主题 / 概念 / 公式 / 符号 / 例题 / 习题）
    ↓
AI 导师用提问的方式带你学（不是直接把答案倒给你）
    ↓
做测验 → 错题自动进错题本 → AI 分析你错在哪 → 针对性再练
```

几个设计上的取舍：

- **本地优先**：课程文件、学习记录、错题本都在你自己的浏览器里，不上传到任何服务器。
- **自带 AI**：项目不提供 AI 服务，你自己填 API Key。用哪家、用哪个模型由你决定。
- **本地解析**：PDF 解析、OCR、分块全部在浏览器本地完成，只有"分析"和"提问"才会调用 AI。
- **不评判你**：错题分析只陈述可观察到的模式（如"符号处理"、"概念理解"），**永远不会**给你贴"粗心"这种标签。

## 核心功能

### 课程资料管理

- 支持格式：**PDF、DOCX、PPTX、图片（PNG / JPG / WebP / GIF / BMP）、粘贴文本**
- **批量上传**：一次可选多个文件，每个文件生成一份独立文档（最多 50 个/批，并发处理 2 个）
- **文件大小**：没有固定上限，只看本机浏览器剩余的存储空间（空间不足时会提示还剩多少）；单个文件最大 2 GB，这是浏览器一次能读入的上限，更大的文件可以按章节拆开上传
- 上传后自动在**本地**完成：文本提取 → 结构识别 → 语义分块
- 图片走**本地 OCR**（tesseract.js），不联网
- 每个分块都保留来源引用，例如 `Calculus.pdf · Page 12 · § 导数`
- 重复文件会被识别并跳过，不会静默创建重复文档

### AI 课程分析

- 一次性提取：**主题、概念、公式、符号、例题、习题、先修知识**
- **读完整本教材**：长教材按章节分成若干部分分别分析再合并（约每 4 万字一次 AI 请求），不再只读开头；以前只分析了开头的大教材会提示“重新分析”
- 符号会记录"上下文"，因此同一个符号在不同主题下可以有不同的含义
- 采用**流式请求**，长课程分析不会因为固定超时而中断
- 分析失败时会明确告诉你原因（如"输出被截断"、"API 密钥无效"），并保留已提取的文档与文本

### AI 导师（AI Tutor）

问答式学习，而不是直接给答案：

```text
简短讲解 → 提问 → 你作答 → 评价 → 反馈 → 渐进提示 → 下一题
```

- 回答基于你的课程资料；超出资料范围的内容会明确标注为"补充说明"
- 提供**渐进提示**（逐步给，不直接给答案）
- 每次会话都保存在本地，可在"对话记录"里回看
- 化学 / 生物讲解会配图：课程资料里的原图优先显示；此外可由本地计算画出**分子结构式、反应能量图、滴定曲线、遗传棋盘格、系谱图、转录与翻译（中心法则）**——AI 只提供课时中的事实，分子式、ΔH / Eₐ、每个 pH、配子与比例、代数分层、氨基酸序列都在本地计算，算不对的图会被丢弃而不是画错
- 按大学深度：滴定支持**多元酸**（如磷酸，三个计量点）和**弱碱**；遗传支持**伴性遗传**（儿子 / 女儿分开给比例）、**复等位基因与共显性**（ABO 血型）；系谱图会自动分析**可能的遗传方式**（常 / X 连锁、显 / 隐性、Y 连锁）并说明排除理由；转录翻译区分**链的书写方向**、从**起始密码子 AUG** 开始；统计支持 **t / χ² / F 分布**与**卡方拟合优度检验**（χ²、自由度、p 值、结论）
- **其它理科也有可交互的图**（同样由本地计算，AI 只提供讲解里的公式和数据）：
  - **公式探索器**（所有理科）：讲解里的公式配上参数滑块，拖动即可看到曲线如何变化，虚线保留原曲线，可一键还原
  - **微积分**：切线与导数（可拖动切点、割线逼近）、黎曼和（左 / 右 / 中点 / 梯形，分段数可调，与定积分比较误差）、泰勒多项式（阶数 0–10 逐级逼近）
  - **物理**：受力分析（合力、是否平衡、加速度，可画斜面）、运动图像（x-t / v-t / a-t 联动，含位移与路程）、透镜 / 面镜光路图（可拖动物距，判断实像虚像、正立倒立、放大缩小）、串并联电路（等效电阻及各电阻电压、电流、功率）
  - **统计**：回归直线（R²、斜率检验、置信带与预测带）、均值的置信区间（z / t，可调置信水平）
  - **化学**：反应动力学（0 / 1 / 2 级，半衰期与线性化图）、阿伦尼乌斯图（由数据拟合活化能）
  - **生物**：酶动力学（米氏曲线与双倒数图，四种抑制类型）、种群增长（指数 / 逻辑斯谛，拐点与最大增长速率）
  - **计算机**：排序算法逐步回放（冒泡 / 插入 / 选择 / 归并 / 快排）、二叉搜索树（逐个插入、四种遍历）
- 化学、生物、概率统计的科目说明已按大学深度改写（热力学 / 动力学 / 有机反应机理；链极性、伴性遗传、χ² 检验、哈代-温伯格；t / χ² / F 检验的前提与自由度等）
- **医学（临床 / 口腔）**也有本地计算的图：
  - **生理**：膜电位（能斯特 / GHK，可拖动细胞外 K⁺ 浓度）、动作电位（神经 / 心室肌 / 窦房结分期）、氧解离曲线（右移因素、血氧含量）、心室压力–容积环（每搏输出量、射血分数、心输出量）、肺容量（肺量计曲线）、肾小球滤过与清除率、酸碱平衡（Davenport 图，按国内病理生理教材的代偿公式判断是否合并其它紊乱）
  - **生化与药理**：氨基酸带电与等电点、糖代谢 ATP 计算（可切换 P/O 比与穿梭方式）、药代动力学（一室模型血药浓度曲线、多次给药与稳态，可调剂量与间隔）
  - **形态与口腔**：牙位图（FDI / Universal / Palmer 互换）、胚胎发育 / 牙萌出时间轴、神经传导通路（逐级神经元与交叉平面）、解剖对照表（起止点、神经支配等，可一键加入复习卡片）
  - 医学讲解会遵守安全边界：只做教学，不对真实个人做诊断、不给治疗或剂量建议；例题中的参考值与剂量仅为示意

### 作业完整讲解

- 作业页新增「完整讲解」标签：像讲义一样把整份作业讲完——开头讲**本次作业必须掌握的工具**，然后**逐题**给出结论、完整步骤（每一步写出行变换和变换后的矩阵 / 算式）、如何读出结果和验算，最后是**小结表与复习建议**（哪类情况对应本次作业的哪几题）
- 上传了教授答案并已对上题号的题，以教授答案为准；讲解语言跟随「题目语言」设置（默认中文、关键术语附英文）
- 逐部分生成（每题一次请求，最多同时 2 个），完成一部分就显示并保存；题目或答案改动后只提示更新受影响的部分，不会自动重跑
- **线性代数本地核对**：讲解中每个增广矩阵都会在本地用精确分数重新化成 RREF，与讲解写的结果和结论（无解 / 唯一解 / 无穷多解）对比，不一致会标出并给出正确的 RREF
- **划词 / 划段提问**：在讲解里选中文字或公式，点「解释」或「提问」，回答会出现在**可拖动、可调大小、可最小化**的浮动窗口里，可以继续追问（会带上前面的问答）
- **保存问答**：问答收到回答后自动保存（也可点「保存」），之后的追问也自动保存，窗口 / 小卡片 / 收进原文的状态与位置刷新后保留；保存过的原文在讲解中会标记出来，点一下就在原来的位置重新打开；「我的问答」可搜索、打开、重命名、删除；讲解重新生成后找不到原文的问答会保留并标为“原文已更新”
- 问答可一键**加入复习卡片**；整份讲解可**打印 / 导出 PDF**（浏览器打印对话框里选“另存为 PDF”）
- 做题模式下第一次打开会提示“完整讲解包含全部解法”，避免不小心看到答案

### 公式与符号

- 从课程资料中提取的**公式**（KaTeX 渲染）与**符号**集中展示
- 支持搜索，点击即可复制
- 同一个符号的不同含义会作为独立条目保留

### 划词翻译

- 在页面中**选中任意文字**即可弹出翻译
- 会带上上下文段落，让翻译更准确
- 翻译目标语言跟随你的设置（中文 / 英文）

### 测验（Quiz）

- 从课程分析结果生成题目，**题目有据可依**（来自你的资料）
- 题型见下方"支持的测验题型"
- 支持：主题选择、题目数量、起始难度、题型组合
- 答题后可查看解析、参考答案与"再来一组"（同主题 / 相似 / 更难 / 更简单 / 薄弱点强化）

### 错题本

- 答错的题目**自动收集**，同一道题多次答错会合并
- 由 AI 分析：**从哪一步开始偏、关键错误是什么、为什么这一步不成立、正确思路**
- 错题可标记为"已掌握"或归档
- 提供**薄弱点提示**（"可能需要复习的部分"）

### 复习卡片（间隔重复）

- 适合需要大量记忆的课程（解剖、组织学、名词解释）：从课程概念一键生成（名词 → 解释），在讲解里的解剖对照表上一键加入，也可以自己写
- 复习时先看正面、回想后翻面，按“忘了 / 困难 / 记得 / 简单”评分，系统据此安排下次复习时间（10 分钟到数月不等）；键盘空格翻面、1–4 评分
- 与课程概念关联的卡片，复习结果会以较低权重计入掌握度
- 完全本地，不调用 AI

### 背单词

- 侧栏「单词」板块，与课程无关、所有课程共用一份进度
- 内置中考 / 高考 / 四级 / 六级 / 考研 / 托福 / 雅思 / GRE 词书（首次进入选一本，推荐四级），按词频从常用到少用排列；释义来自开源词典 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）
- 按 FSRS 记忆算法（[ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)，MIT）安排复习：每天先复习到期的词，再学新词（每天新词数可调）
- 复习方式由易到难：先认读（看词想义），熟了之后轮换拼写（看释义写单词）、填空（课程原句挖空）、听写（浏览器朗读）；拼写自动判分，差一个字母会提示
- **课程词汇**：从课程资料里找出常用词和四级以外的生词，附上第一次出现的原句和页码；词典查不到的专业词由你配置的 AI 补释义（未配置 AI 时只保留词典能查到的释义）
- 易错词：拼写 / 填空 / 听写写错的词单独列出并可专项练习
- 可以导入自己的词表（每行一个单词，或「单词 + 释义」）
- **导出到其它软件**：Anki（制表符 .txt，正面单词，背面音标、释义、例句）、Excel / WPS 表格（.csv）、纯单词列表（.txt）；可导出任意词书、已学单词或易错词

### 自适应练习与掌握度

- 难度根据近期正确率、连对/连错、知识点掌握度动态调整
- 掌握度是**基于练习记录的估计值**，不是对能力的绝对测量
- 提供知识点维度的掌握度视图（最薄弱的排在前面）

### 本地优先数据存储

- 所有数据存于浏览器 **IndexedDB**（Dexie，45 张表，schema v17）
- 课程原始文件字节同样保存在本地
- 无需后端、无需注册账号、无遥测
- 首次启动会预置两个演示邀请码（见下方"首次使用"）

## 支持的测验题型

| 题型              | 说明                                                                                                                                                                                                                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **单项选择题**    | 4 个选项，选择一个                                                                                                                                                                                                                                                                                        |
| **判断题**        | 正确 / 错误                                                                                                                                                                                                                                                                                               |
| **数值题**        | 输入数值，按容差比较                                                                                                                                                                                                                                                                                      |
| **数学表达式题**  | 输入表达式，按数学等价判断（如 `x^2/2` 与 `0.5x^2` 视为等价）                                                                                                                                                                                                                                             |
| **简答题**        | 用自己的话作答，按**得分点**计分：每道题有 2–6 个得分点，答到几个得几个（例如 3/5 = 60%）。AI 逐点核对，答到的点会引用你写的原话作为依据；不同意判定可以申诉，申诉后不计分                                                                                                                                |
| **代码输出题**    | 计算机科目：写出程序的确切输出，逐字符判分                                                                                                                                                                                                                                                                |
| **化学方程式题**  | 化学科目：写出（配平的）化学方程式，如 `2H2 + O2 -> 2H2O`、`Fe^3+`、半反应 `MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O`、有机结构式 `CH2=CH2 + H2 -> CH3CH3`。本地检查物质是否齐全、原子与电荷是否守恒，并指出缺了什么或哪里没配平；有机物结构写法与参考答案不同（可能是同分异构体）时不判对错，提示你对照参考答案 |
| **排序题**        | 把步骤 / 过程按正确顺序排列（拖拽或上下按钮）。按“最长已排对的顺序”给部分分，例如 4 步中只有一步放错得 3/4                                                                                                                                                                                                |
| **X 型多选题**    | 选出所有正确选项（至少两个正确）。给部分分：每选错一个抵消一个选对的，例如正确答案 ABC，选 AB 得 2/3，选 ABD 得 1/3                                                                                                                                                                                       |
| **B 型配伍题**    | 一组共用的备选答案，为每个题干各选一个（同一答案可重复使用），每个题干单独计分                                                                                                                                                                                                                            |
| **填空题**        | 每个空可接受多种写法（如“乙酰胆碱”“ACh”“乙酰胆碱（ACh）”），忽略空格、全半角与标点；本地对不上时，若已配置 AI，会让 AI 只判断你的写法是否与答案完全等价（同义词 / 英文 / 缩写），得分仍在本地计算                                                                                                         |
| **冠词题**        | 外语课（德语）：给出课本里的名词，按 1–3 选 der / die / das，课本写了复数时再写复数。冠词 1 分、复数 1 分；复数只差变音或大小写得半分                                                                                                                                                                     |
| **变位 / 变格表** | 外语课：课本里的动词变位、名词变格或匈牙利语后缀表，部分格子留空，逐格判分（拼写完全正确 1 分，只差重音 / 大小写 / ß 与 ss 得半分），Enter 跳到下一格                                                                                                                                                     |

> **说明：简答题需要连接 AI 才能判分。** 没有配置 AI 时，简答题会显示得分点和参考答案，但不计入成绩。
> 教授练习题和 AI 导师里的简答题也按同样的得分点方式判分，并计入错题本与掌握度。
>
> 带单位的数值题支持大学常用单位：`mol/L`、`M`、`mM`、`µM`、`kJ/mol`、`kcal/mol`、`J/(mol·K)`、`atm`、`Torr`、`kDa`、`ppm`、`Å`、`eV` 等，以及医学常用的 `mmHg`、`bpm`、`mOsm/L`、`mEq/L`，任意同量纲单位先换算再比较（渗透压单位与 `mmol/L` 不互换）。

数学等价判断使用 `mathjs`：先尝试符号化简，再用数值采样验证，因此**不依赖 AI 判分**，
结果可复现。无法确定时会明确显示"无法自动判定"，而不是猜测对错。

## 数据与隐私

- 本项目采用 **Local-first** 设计：课程文件、分块、学习记录、错题本、AI 设置都保存在**本机浏览器**中。
- 本仓库**不包含**任何用户课程资料、个人 API Key 或学习数据。
- PDF 解析、OCR、分块等处理**在本地完成**，不联网。
- 当你配置了 AI API 后，**相关内容会发送给你所配置的 AI 服务商**：
  - 课程分析：会发送用于分析的分块文本
  - 导师提问 / 测验生成：会发送相关片段与你的作答
  - 划词翻译：会发送选中的文本与上下文段落
  - 请求**只包含完成任务所必需的内容**，不会发送你的整个文档库
- 数据是否被服务商留存、如何使用，**取决于你所选择的 AI 服务商及其政策**，本项目无法控制。
- API Key 以 **AES-GCM** 加密存储，密钥为不可导出的设备密钥。
- **联网参考图片（默认关闭）**：在「设置 → 联网参考图片」开启后，化学 / 生物 / 医学讲解页会出现「查找参考图片」按钮（医学优先查找公有领域的格氏解剖学图版和 CC 授权的组织切片图，从不检索患者照片）。点击时会把**主题的搜索词**（如化合物名称、“线粒体结构图”、“Gray brachial plexus”）发送给 **PubChem** 和 **Wikimedia Commons**，不会发送你的课程资料。图片保存在本机，并注明来源、许可协议和作者；只采用允许再使用的许可（公有领域、CC0、CC BY、CC BY-SA）。可选“用 AI 模型核对每张图片”，此时图片会发送给你配置的 AI 服务商。

> 换句话说：**在你不使用 AI 功能时，数据不离开本机；一旦调用 AI，相关片段会发送到你自己配置的服务商。**

- **掌握度一致**：练习作业、模拟考试与复测的检查结果统一计入掌握度（本地核对计全权重，AI 判断计半权重，与测验简答题相同），判定异议重算时保留。
- **导入校对**（作业页「校对」）：左边原图（PDF 页面在本机渲染），右边识别出的题目与已对上的教授答案，可直接修改文字、题号、拆分 / 合并小题，实时预览公式；自动标出容易识别错的地方（短横当负号、`m/s2` / `x10-1` 这类丢了上下标、矩阵、表格、被拆开的分数、小题分界、原文里没有的数字），分数 / 表格 / 矩阵处提示「建议对照原图校对」。每题可标「已核对」，题目导航显示核对状态；识别完成后提示「建议先校对识别结果（n 题未核对）」。每次修改都保留记录（时间、修改前后、错误类型）；由旧文字生成的内容（教授答案对应、提示与解法、讲解这一节、与教授答案对照、复习讲解、检查答案、引导练习、练习作业）标为「需重新确认」，一键重新确认或重新生成；之后的讲解、检查答案和提问只用修改后的文字，重新识别也不会覆盖你的修改。
- **检验用途**（每题、每份作业、每个文件）：「回归用例」（已知识别错误片段）/「开发集」（可看答案、用来调试）/「独立检验」（留作检验：不进入任何 AI 上下文——课程分析、导师、测验取材、练习作业、改编题、其它题的讲解、出题习惯、课程词汇——只在「自测」里做）。用来调试过的题会提示应属于开发集。
- **自测**：独立检验的题不给提示、讲解和 AI 问答，提交后才显示答案；可「检查答案」或自己判定，结果作为留作检验的结果计入掌握度（不进错题本）。
- **检验网站**（作业页）：分别检验三种能力——独立解题（写讲解的模型看不到教授答案，再与教授答案对照）、依据教授答案讲解、批改学生作答（与录入的教师评分比较）——以及来自导入校对的识别准确性（按负号 / 上标 / 下标 / 分数 / 矩阵 / 小题分界 / 题号统计）。开发集与独立检验分开统计，每个数字标出 n；只在点击时运行，可暂停 / 继续；每次运行保存为检验记录（时间、模型、提示词版本、各项计数），可导出 Markdown / JSON。「与教授答案对照」只是辅助，最终正误需要懂这门课的人判断。
- **题目来源与得分点来源**：题目标「原题 / 改编题 / AI 新题」；得分点标「教授评分标准」或「平台拟定的得分点（非教授标准）」。
- **作业题目的知识点与考试范围**：本地匹配课程主题与考点清单，显示在题目上方（不调用 AI）。
- **PDF 读取更准确**（只对之后上传 / 重新处理的文件生效）：上标与下标按字的位置还原（`21.5²`、`m/s²`、`v_{fy}`、`×10⁻¹`、`× 10²²`、`60°`），上下叠放的分数还原为 `1/2`、`(a)/(b)`，对齐的表格还原为表格；粗体 / 斜体数学字母（`𝟐𝟎. 𝟗`、`𝑣𝑣`）变回普通文字；Symbol 字体的 λ、α 与 Wingdings 的项目符号 / 对勾按各自字体正确显示；修复部分浏览器上 − Δ π ° 等字符被悄悄丢掉的问题。拿不准的分数、表格、上标、矩阵保留原文，并提示「建议对照原图校对」。
- **结构与题号**：没有章节标题的课件按文件名（`Ch03.pdf`、`Unit 2 …`、`第3章`）归为一章；跨行的「Unit 3: …」标题合并，「A/ …」「B/ …」分隔页识别为小节。教授答案支持 `Advanced Problem 2.1`、`Problem 2.1` 这类题号，不再把掉到行首的上标 `2` 误当成第 2 题。
- **拍照的批改试卷**：识别时发现手写或批改痕迹，会在文件上提示「这张图片含手写或批改痕迹，识别文字可能不准；作业检查与问答可改用支持看图的模型」。

## V0.9.0 更新

本版是一次大更新：作业完整讲解全面升级（题目分析、详细版、步骤卡片、引导练习、做练习题、导入讲解、按教授答案对齐、原题中文翻译）、国际医学生适配（外语课、考点清单、口试、模拟问诊）、题库式自适应测验、作答图片与 Apple Pencil 手写板、AI 用量与余额、所有生成可暂停、平板触控适配、更省 token，以及一轮全站审查修复。各项说明如下。

### 更省 token：同样的操作发更少的重复内容

- 测验、交互导师、分小题的完整讲解与详细版、做练习题、口试的请求改为「固定内容在前、每次变化的内容在后」，DeepSeek / OpenAI 等服务商的自动前缀缓存能命中更多（命中部分通常只收约 1/10 的价格）；测验的系统提示只写本次所选题型的规则，「避免重复」只列最近 30 题的开头，补题不再把全部教材片段重发一遍；没有出处的作业题不再把题目原文当作「来源段落」重复发送。离线测量（`npm run token-usage`，不联网）：受影响的操作折算输入减少 20 %–34 %，见 `docs/token-usage.md`。已生成的讲解、课时等缓存内容不受影响，不会显示「可更新」。
- 设置页新增「轻量模型（可选）」：同一服务商、同一密钥下更便宜的模型，只用于单词释义、填空与简答题核对、题目翻译、考点匹配、提取得分点；留空则全部使用主模型。

### 导入讲解：长文件不再被截断，生成的讲解保留可切换

- 导入较长的讲解（如二十多页的 PDF）时不再报「模型尚未完成回复就停止了」：每次读取的分量按当前模型的输出上限计算；回复被截断时自动加大输出预算，到上限仍放不下就把这一部分对半拆开再读（不会从公式中间拆开），结果在本地按顺序拼好。某一部分失败时，已读完的部分保留，提示写明是第几部分、为什么（例如模型单次输出上限），点「继续导入」只重读失败的那部分。
- 导入后**原来生成的讲解不会被替换**：节标题旁出现「生成的讲解 / 导入的讲解」切换，两份都完整保存（生成的讲解连同它的详细版、上一版一起保留）。重新生成这一节、按教授答案修改都只改生成的讲解，导入的版本一直保留；「可更新」只看生成的讲解。之前导入过的节再导入时才会替换（旧的导入版本可用「恢复上一版」找回）。

### 原题中文翻译

- 「查看原题」和做题页的题面可在「原文 / 中文翻译」之间切换（题目本身是中文时不显示）。第一次点「中文翻译」时请 AI 逐句翻译（不是题意复述），公式、符号、小题编号和数字保持原样，术语首次出现附英文；本地核对公式 / 编号 / 数字没被改动，否则提示重新翻译。译文保存在题目上，题面变了才需要重新翻译。

### 讲解与教授答案对齐

- 上传并对应好教授答案后，有教授答案的题重新生成讲解时**按教授的方法、步骤顺序、行变换、记号与答案形式**来写；别的方法或额外检验放在后面、标为「补充（考试不要求）」；教授答案里出现的小题（包括写在别的小题解答里的内容）都会覆盖，教授未解答的小题会注明；教授答案的明显笔误按原意写并加一行说明。这些题会显示「可更新」，没有教授答案的题不受影响。
- 每节新增「与教授答案对照」（工具栏「对照全部有教授答案的题」可批量对照，可暂停 / 停止）：逐小题列出 一致 / 方法不同 / 结果不同 / 讲解缺少 / 教授未解答，附教授原文引用；点「按教授答案修改」才会重写（旧版本可恢复），或「保持现状」。按教授答案写成的节标「已按教授答案」（打印同样显示）。

### 问答小卡片显示完整回答、可调整大小

- 「缩成小卡片」后卡片显示最新的问题和**完整的**最新回答（含公式），默认宽 320 px、高度自动贴合内容；内容太长时最高到屏幕高度的 60%（且不超过 520 px），其余在卡片内滚动（有滚动条，未到底时底部渐隐）。新回答到来时自动重新贴合。
- 拖动卡片右下角可调整大小（最小 240×120，触屏把手 44 px）；手动调整后保持该大小，再次缩成小卡片沿用，已保存的问答下次打开也记住。固定在屏幕上 / 跟随页面两种方式都适用，切换时大小不变。

### 输出上限与长讲解的「必须掌握的工具」

- **设置 → 最大 Token 数**新增「使用模型允许的最大值」（新安装默认）与「手动设置」（范围扩大到 64 – 128000；已有的数字保留为手动）。模型上限优先读取服务商模型列表里写明的输出上限，其次是官方文档写明的值（gpt-4o / gpt-4o-mini 16384、gpt-4-turbo / gpt-3.5-turbo 4096、deepseek-v4-pro 384000），都不知道时用你填的数字；请求从不超过模型上限，也始终会发送上限（不发送时部分服务商默认很小，长讲解会被截断）。设置页显示当前模型实际使用的上限与来源。
- **完整讲解**：截断后的输出预算可以翻倍到上述上限（以前固定最多约 16k）。「必须掌握的工具」与「小结」改为两次独立的、更小的请求；某一部分仍太长时按题目分组（对半，直到单题）分别生成再在本地合并，已完成的组会保存，暂停后继续只补剩下的。真的到了模型上限仍放不下时，提示「当前模型单次最多输出约 X token，这一部分仍然太长」并建议换用支持更长输出的模型。已生成的开头与小结不会因此变成“可更新”。

### 快捷输入按钮

- **引导练习的行变换框**：旁边一排常驻按钮——按矩阵实际行数生成的 R1…Rn、`→`、`↔`、`+`、`−`、`/`、`,`，三个模板「Rᵢ → Rᵢ − kRⱼ」（插入 `R? -> R? - ?R?`）「交换」（`R? <-> R?`）「倍乘」（`R? -> ?R?`）与退格。模板插入后选中第一个 `?`，直接输入即覆盖，Tab / Shift+Tab 在 `?` 之间跳转；选中 `R?` 的 `?` 时点 R2 只填数字。

- **引导练习的填空**：按题型只给相关的按钮——表达式给答案里出现的变量 + `xⁿ`、`√`、分数、`π`、括号；带单位数值给答案里的单位（经单位判分器解析）+ `·`、`^`、`×10ⁿ`；化学方程式给 `→`、`⇌`、下标 ₂₃₄、上标、`⁺`、`⁻`、`(aq)` `(s)` `(l)` `(g)`；统计课的文字填空给 μ σ x̄ p̂ χ² H₀；语言课的文字填空给该语言的字母。

- 按钮插入在光标处、有选区时模板包裹选区，点按不会让输入框失去焦点；键盘 Tab 可到达；电脑上紧凑，触控时每个按钮 ≥44px。

### 平板：手指与触控笔的交互

- 课程主页新增「教授出题习惯」标签：点击「分析教授出题习惯」后，AI 从本课程的作业题目、教授练习题与往年试卷 / 考试大纲里像题目的段落总结教授怎样出题——题型、大题结构（小题数、递进或并列）、题干措辞、记号、数字特点、常设陷阱、答案要求、难度。**每条都附原题例子**，例子必须能在发出的题目原文中找到，找不到的条目直接丢弃；可展开查看例子并跳到来源。
- **增量更新**：之后只把新的或改动过的资料（抽样）连同当前档案发给 AI，由它补充、修订或删除条目；删除的资料连同它的例子一起移除（不调用 AI）。识别新作业后作业页会提示「去更新档案」，但**从不自动调用 AI**；更新可暂停 / 立即停止 / 继续。
- 条目可以**编辑、删除、手动添加**；你写过或改过的条目之后的更新不会改动。「全部重新分析」只替换 AI 写的条目。
- **「模仿教授出题」**（默认开启，可关闭）：开启且档案不为空时，「做练习题」、测验（主题 / 混合复习 / 按考试范围）与口试练习的出题请求会附上一段简短的教授习惯（约 600 token 以内，例子多的条目优先）；关闭或没有档案时出题请求与以前完全相同。本地构造的线性代数方程组（精简版）会按档案中写到的矩阵大小、「只用整数」与增广矩阵 / 方程组写法调整。
- 档案存在课程上下文里，随数据导出 / 恢复，删除课程时一起删除。

### 作业完整讲解：讲解末尾「做练习题」

- 完整讲解的小结下方新增「做练习题」，有两个版本：**完整版**按原作业一一对应（题目与小题数量、题型、解的类型都相同，只换数字与情境）；**精简版**按小结的分类每类一题，另加 1–2 道综合题。
- **线性代数的方程组题在本地构造**：按原题的大小和解的类型（无解 / 唯一解 / 1–2 个自由变量）生成数字友好的整数增广矩阵，标准答案用精确分数本地计算，不花 token。**其它科目的题由 AI 出题**（不做本地模板）；能在本地核对的答案（方程组、数值、化学方程式配平）先核对，对不上就不收。
- **所有题目（包括本地构造的）都经一次批量 AI 审核**：是否考到原作业的知识点、完整版的结构与解型是否对应、题意是否清楚、难度是否相当；审核只给通过与否和原因，不改题目和答案。没通过的题重新出一次再审，仍不通过就去掉，并告诉你少了几题、为什么。
- 结果存为挂在原作业下的「练习作业」（作业页在原作业卡片下列出，可单独删除；删除原作业时一起删除；随数据导出）。练习作业可以做题、检查答案（有本地答案时直接本地判分）、引导练习和按需生成完整讲解；检查过的作答计入掌握度与错题本。出题可以暂停 / 立即停止 / 继续，进度保存在本机。

### 作业「引导练习」

- 作业页「做题 / 完整讲解」旁新增「引导练习」：按这道题完整讲解的步骤（有详细版时用详细版）一步一步自己做，每一步在本机即时核对，不花 token。做题页的提示卡片也可以直接进入；原来线性代数的「六步学习引导」由它取代（「从哪里开始」的方法提示保留在引导练习的题目下方）。
- **行化简题**：每一步先写行变换（`R2 -> R2 - 2R1`、`R_2→R_2-2R_1`、`R1 <-> R2`、`R2 -> 1/3 R2`、`交换 R1 R2` 等写法都认，多个变换用逗号隔开），变换正确后才开放结果矩阵；「一键填入未变的数据」填好这一步没有改动的行；矩阵逐格用精确分数核对（`-2/5`、`−0.4` 都算对），错的格子标红并给出该格应计算的算式；本步全对才进入下一步。走与讲解不同但合法、并且更接近行最简形的路线（例如先消元再化主元）也算对；不是初等行变换（如 `R2 -> 2R1`）或没有进展的变换会说明原因。最后的结果与讲解的行最简形一致。
- **其它科目**：第一次使用时用一次简短的 AI 请求把已有讲解转成带空格的步骤（可停止），结果保存复用；每个空格的答案必须出现在讲解里，否则不出这个空。空格按科目用本地判分：式子看等价、物理数值带单位 1%、化学方程式看配平与物种、统计数值容差、生物 / 医学数值或可接受答案、计算机精确匹配。
- 卡住时可以看「提示」（讲解对这一步的说明）或「看这一步答案」（标记为已查看）；做完显示小结（完成步骤、用过提示、看过答案），可「重新开始」。进度按题保存在本机，刷新后接着做，并计入你的作答（有进度的作业文件不能直接删除）。两种界面风格与暗色模式都适用，按钮与输入格适合平板触控；Tab 在格子间移动，Enter 检查。

### 作业完整讲解：普通版 / 详细版、排版改进

- **普通版 / 详细版**：每题标题旁可以在「普通」和「详细」之间切换。详细版把每一步计算展开（行变换逐个元素写出算式、每次变换后的完整矩阵、分数通分约分；其它题型同样补全跳过的步骤），第一次切到详细版时才生成，并且对照已有的普通版来写，结论、记号和步骤顺序保持一致；两版都保存，之后切换不再花 token。设置页可选默认显示哪个版本；作业页「全部切到详细版」只生成还没有的那几题，可以暂停 / 继续。两版都做线性代数的本地核对；「重新生成这一节」只重写当前显示的版本，「恢复上一版」同样适用。
- **更好读的排版**（旧讲解直接生效）：正文每行约 70 字，公式靠左跟在说明下方，矩阵里的分数用正常大小，术语只在第一次出现时加粗、每段最多两处强调结果，每个小题末尾如果还没有框出答案会再框一次。
- **行变换步骤卡片**：「作 $R_3 \to R_3 - 3R_1 - 2R_2$」加上后面的矩阵会显示成编号的步骤卡片：原矩阵 → 新矩阵并排，箭头上写着变换，改动的行浅色高亮。鼠标悬停或用键盘聚焦改动的行 / 数字，会显示它是怎么算出来的（本地用精确分数计算，不调用 AI）；如果讲解写的数和本地算的不一致，会在该位置标出并给出正确值。读不懂的步骤按原样显示，不会误报。

### 作业完整讲解：导入讲解、问答标记样式

- **导入讲解**：完整讲解页的「导入讲解」可以上传你已有的讲解（PDF、Word、照片、Markdown 或文本），或选择已上传的文件。AI 只负责把它重新排版成平台的公式格式，并按本作业的题号拆分；原作者的计算保持原样，AI 认为可能有误的地方单独标为「这里可能有误」并给出建议（可选「只排版，不核对」省 token）。在文件中找不到的内容不会被导入；线性代数的行化简仍在本地核对。导入的节标「来自导入」并可打开原文件；划词提问、保存问答、重新生成这一节、补充题目分析都可照常使用。替换已有的讲解前会先确认，旧版本可用「恢复上一版」找回。长文件分部分读取，可以暂停 / 继续。上传的文件作为参考资料保存，不会用于课程分析、出题或导师讲解。
- **问答标记样式**：设置页新增「问答标记样式」——链接样式（强调色文字 + 下划线）或荧光笔样式（半透明底色）；已保存的问答比未保存的标记更深，颜色随配色主题与明暗模式变化。
- 上传资料现在也接受 `.txt` / `.md` 文本文件。

### 作业作答：上传手写图片、Apple Pencil 手写板

- 「你的作答」下新增「上传图片」和「手写板」：符号多、打字不便时，可以上传或直接拍照手写过程，也可以在网页里的手写板上用 Apple Pencil（或鼠标）书写。每题可放多张图片，缩略图可以放大、调整顺序、移除；只有图片没有文字也能「检查答案」。
- **手写板**：笔或鼠标才会落笔，手指只用来滚动，笔在屏幕上时会忽略手掌；有压感，可切换笔 / 橡皮（Pencil 的橡皮端也可以）、撤销 / 重做 / 清空、三种粗细、黑色和三种主题色、空白 / 方格 / 横线纸，可以加页。纸张在暗色模式下也保持白色；保存后每一页成为一张作答图片。
- **图片只保存在本机**（会随作业保存、导出和恢复；删除题目、作业、作业文件或课程时一起删除；有图片的作业文件算作有作答，不能直接删除）。图片压缩到长边不超过 2000 像素，单张不超过 8 MB。
- 「检查答案」和逐题 AI 问答只会把**本题**的图片发给 AI。如果当前模型不能看图，会提示「当前模型不支持识别图片，请换用支持看图的模型或改为打字」，并只使用打字内容；不会在本地猜测手写内容。

### AI 用量与余额、自动获取模型列表

- **用量统计**：每次 AI 响应返回的 token 用量（输入 / 输出 / 缓存命中）记在本机，按月份和用途（作业、测验、课程分析、导师、判分、问答、单词、其它）分类。设置页「AI 用量与余额」可看本月 / 上月明细，可重置。只记数量，不记内容和密钥。
- **余额**：DeepSeek 直接查询账户余额；OpenAI 可选填管理员密钥（`sk-admin-…`，加密保存、不导出）查看**本月已花费**；其它服务商（Qwen、MiniMax、MiMo、自定义）显示本机统计，填写每百万 token 单价后显示**估算**花费。服务商不允许网页直接查询时会说明并改为显示本机统计。
- **显示位置**：精密实验室风格在侧栏底部（替换原来的「数据保留在你的设备上」），讲义风格在右上角账户菜单；点击跳到设置页对应部分。**默认不显示**，在设置页「AI 用量与余额」勾选「在侧栏 / 顶栏显示用量与余额」后才出现；关闭时不会为它查询余额，用量照常统计。
- **获取模型**：填好 Base URL 和密钥后，模型栏旁点「获取模型」（离开输入框或保存时也会自动获取），模型栏变成可搜索的下拉框，仍可输入任意名称；服务商不支持或浏览器拦截时保持手动输入并说明原因。

### 题库式自适应测验

- 难度选「自适应」时，出题会先生成一个包含多个难度的**题库**（大约是题数的 2–2.5 倍，出题时间更长），作答时每答一题，系统按你之前的作答记录（正确率、连对 / 连错、知识点掌握度）从题库里挑选下一题的难度。
- 测验长度不变；没用到的题库题不会显示、也不计分。结果页显示这次的难度路径（例如 基础 → 中等 → 进阶）。中途关闭页面后可以继续作答。
- 复习错题会话、「练这道错题」和固定难度的测验与以前相同。

### 所有 AI 生成都可以暂停 / 停止

- **分多步的生成**（作业完整讲解、作业识别与提示 / 解法、教授答案讲解、测验与口试出题、课程分析、课程词汇释义、课本词表导入、短语卡、考点 AI 匹配、问诊情景提取）在进度条右侧有「暂停」和「立即停止」：暂停会先完成正在进行的部分再停下，立即停止会马上中断；已完成的部分都会保留，「继续」只做剩下的部分，不重做。
- **暂停的测验**在测验首页显示为「未完成」，点「继续出题」补齐剩下的题后才能作答。
- **课程分析**暂停时旧的分析结果保持不变；已读完的部分本次浏览内会保留，刷新页面后需要重新读取。
- **只有一次请求的生成**（导师课时、按幻灯片学习、交互导师、划词问答、错题分析、简答 / 填空核对、作业单题提示 / 解法 / 讲解 / 检查答案、参考图片、问诊回合与评分等）有「停止」按钮：停止后原有内容不变，你的问题或答案留在输入框里。

### 作业完整讲解：单独重新生成一节、长题自动分小题

- **重新生成这一节**：讲解里每一节（「必须掌握的工具」、每道题、小结）标题旁都有「重新生成这一节」。可以写一句修改建议（可选），例如「步骤再详细一点」「用 s 表示自由变量」「先解释为什么第四列不是主元列」；AI 会看到当前版本并按建议修改，同时保持结果正确。只重写这一节，其它部分不变，也不会被标成「可更新」。
- **恢复上一版**：重新生成后保留上一版，点「恢复上一版」可以来回切换（只保留一层）。停止或失败的重新生成不会改动原有内容。
- **长题自动分小题**：有 (a)(b)(c)… 三个及以上小题（或题目很长且有两个小题）的题目，改为每个小题单独请求、按顺序拼成整题讲解；一次写完整题仍被截断时也会自动改为分小题，不再显示「模型尚未完成回复就停止了」。每写完一个小题就保存，暂停、刷新或失败后从下一个小题继续（显示「已完成 2 / 5 小题」）；线性代数的 RREF 核对按小题标注。

### 作业完整讲解：题目分析、不再长时间卡住、方框后的标点

- **题目分析**：每道题在「查看原题」与「结论」之间多一块可折叠的「题目分析」：在问什么、已知条件与记号、各小题任务、用到的知识、答案应写成的形式。新生成和「重新生成这一节」的题自动带上；以前生成的题显示「补充题目分析」，只单独生成这一小块（请求很短，可停止），讲解其它部分不变、也不会被标成「可更新」。
- **不再卡住几十分钟**：每一部分（包括重试）最多约 6 分钟，到时这一部分标为「超时，可重试」并继续写下一部分；重试时进度里显示「第 2 次尝试：上次超时」这类说明。「必须掌握的工具」和小结只读各题的结论与要点（不再读各题正文开头），请求更小、更快。
- **方框后的标点**：居中公式里 `\boxed{…}` 后面的句号 / 逗号、行末方框答案后的「。」在显示时去掉（以前生成的讲解刷新即生效，无需重新生成）；新讲解也要求不再加这类标点。

### 课程大纲与考点清单

- **新资料类型「课程大纲 / 考试题目」**：课程手册、教学大纲、考试题目清单。上传时文件名像大纲（handbook、syllabus、考试大纲…）会提示你改成这个类型；已经当作教材上传的，可以在「考点清单」里一键改过来。大纲本身不是课程内容：不参与课程分析、出题、导师讲解和课程词汇。
- **考点清单**（课程主页新标签）：自动从大纲里读出考点（保留原文和页码，按「期中 / 期末」等清单分组）；读到的太少时可以让 AI 摘抄，但 AI 给出的考点必须在文件里找得到原文，否则丢弃。可以重命名清单、删除 / 合并 / 自己添加考点。
- **每个考点**显示：教材里有没有对应内容（可直接打开课时）、练习次数、根据练习记录估计的掌握度；可以「学习」或「出题」。对应关系先在本地按字面匹配，也可以点「AI 匹配」（AI 只能从已有的课程主题里选）。只上传了大纲时会提醒你上传教材、图谱或讲课幻灯片。
- **按考试范围出题**：测验设置里可选一个考点清单或单个考点。教材中有的考点依据教材出题；教材中没有的考点只有勾选「包括教材中未找到的考点」才会出题，这些题标注为「AI 出题 · 无教材出处」（国际医学课默认勾选）。

### 外语课练习（第三阶段）

- **两种新题型**（只在外语课出现，`quiz-generator/v7`）：**冠词题**（德语课：名词 + der / die / das，可带复数）和**变位 / 变格表**（德语变位、变格，匈牙利语人称后缀等）。名词和词形只能取自课程资料，出题后逐一核对原文，对不上的题直接丢弃；判分全部在本地。外语课的测验默认勾选冠词题、变位表、填空、配伍和单选；其它课程不受影响，以前的测验也不变。
- **导入课本词表**：外语课的文件菜单和「单词 → 课程词汇」里新增「导入课本词表」。AI 按章节读取课本里的词汇表（匈牙利语“词 + 英文释义”、德语“der Kopf, die Köpfe – head”），只保留在原文中找得到的词；确认列表（按课次分组，可改释义、可取消勾选、超长列表分页）后合并进本课程词书，已有的词更新而不重复。德语名词在词书里显示为“der Kopf, die Köpfe”。
- **短语卡**：外语课的复习卡片页新增「从对话生成短语卡」。AI 从课本对话和考试情景中挑出常用问句、答句和固定表达，只保留在原文中逐字出现的句子；确认后生成复习卡片（正面是意思，背面是原句，可选同时生成反向卡片）。

### 模拟问诊（外语课）

- **模拟问诊**（外语课的课程导航新增「模拟问诊」）：练习匈牙利语 / 德语医学语言课的口试——AI 扮演病人，你用课程语言提问（可打字或语音输入，提供该语言的特殊字母按钮），然后用英语总结病例。
- **情景**：「从课本提取情景」从课本里的考试情景卡、角色扮演卡中读出病人信息和必问问题，只保留在原文中找得到的内容并记下页码；课本里没有时可「生成一个练习情景」（简单的 A1/A2 句子，明确标注“AI 生成、不来自课本”）。
- **问诊中**：病人只按情景卡回答，问到卡上没有的内容会自然地回答“不知道 / 没有”，不提供任何医疗建议；回答可以朗读（可开自动朗读）。右侧清单显示哪些必问问题已经问到，你的句子有语言错误时可展开查看简短提示。勾选「考试模式」后，清单和提示在评分前都隐藏。
- **评分**：问题按你的提问计数；听懂的信息必须在你的英语总结里找到原话才算，分数在本地计算；交流分是 AI 的估计值（0–3 分，附一句说明）。必问问题正好 7 个时，同时按课程的 20 分制（7 + 10 + 3）显示。没问到的问题可以一键加入短语卡。所有问诊记录保存在本机，可继续或删除，也随数据导出。

### 口试练习

- **口试练习**（考点清单每个考点和清单标题旁的「口试练习」按钮，或测验设置里的「口试练习」选项；医学课和有课程大纲的课程都有）：从所选考试范围、单个考点或整门课里随机抽 1–5 个题目。每个题目先由“考官”提问（如 “Describe the shoulder joint and the muscles acting upon it”），你口述（浏览器语音输入，国际医学课用英语识别）或输入完整描述，可选 3 分钟倒计时（可关闭）；再依次回答两个追问。
- **判分**：和简答题相同，按得分点逐条核对（解剖类题目的得分点按 组成 / 毗邻 / 运动 / 肌肉 / 神经 / 血供 / 淋巴 / 发育 等结构给出，不适用的类别不列），每个得分点必须在你的原话里找到依据，分数在本地计算。每个题目结束后显示答到 / 没答到的得分点、参考提纲、你的回答（得分原话已标出），可以对判定提出异议。
- **结果与记录**：测验结果页按题目显示得分（含追问）；没答全的进入错题本，掌握度按简答题的半权重计入，考点清单的练习数和掌握度会自动更新。教材里没有的考点只在勾选「包括教材中未找到的考点」时抽取，并标注「AI 出题 · 无教材出处」。

### 作业完整讲解：问答窗口更省地方

- 问答窗口标题栏新增两个按钮：**「缩成小卡片」**——窗口缩成约 280 px 宽的小卡片，只显示标题和最新回答的开头，可以拖动，点卡片或「展开」恢复原窗口（原来的大小）；**「收进原文」**——窗口消失，提问的句子在原文里用虚线标出，鼠标移到这句话上就会弹出问题和最新回答（可「展开窗口」「保存」或加入「复习卡片」），点这句话重新打开窗口，按 Esc 关闭弹出的卡片。
- 小卡片可以**「固定在屏幕上」**（滚动时位置不变，默认）或**「跟随页面」**（随讲解一起滚动），切换时卡片位置不跳；本次访问会记住上一次的选择。小卡片不占「最多 3 个窗口」的名额，最多同时显示 6 张，再多时最靠后的收进右下角停靠栏。
- 已保存的问答也一样：鼠标移到原文的标记上就能看到回答。收进原文的问答在本节下方的问答芯片里也有一个入口（虚线边框），键盘用户可以直接打开。

## V0.5.5 更新

本版根据用户反馈改进测验质量：**答案不再总是 A**、**混合复习覆盖各个主题**、**题目默认用中文（关键术语附英文）**，并提高错误选项的质量。

### 答案不再总是 A

- 以前选项完全照搬 AI 给出的顺序，而 AI 习惯把正确答案放在第一个，导致一整套题答案都是 A。
- 现在保存题目时在本地随机打乱选项：单选、X 型多选、B 型配伍和 AI 导师单选都会打乱。判分按选项文字比对，不受影响。已生成的旧题保持不变。

### 错误选项质量

- 出题提示升级到 `quiz-generator/v6`：错误选项必须是同一章里真实存在、容易混淆的概念；各选项长短、句式和具体程度相近，正确答案不能总是最长、最具体的那个；不能出现荒谬或离题的选项；题干直接问知识本身，不再写“根据讲义提纲……”。
- 本地检查：正确答案明显比所有错误选项都长，或选项重复时，丢弃这道题并自动补一道。

### 混合复习覆盖各个主题

- 以前（v0.5.3 及更早）混合复习可能整套题都围绕同一个随机主题。
- 现在按主题分配题目：主题数不超过题目数时每个主题都会出到，主题更多时每次随机抽取；每批只给 AI 它负责的那几个主题的原文和知识点；题目记录各自所属的主题。

### 题目语言

- 测验设置新增“题目语言”：**中文（关键术语附英文）**（默认）、**跟随教材语言**、**英文**。选择会被记住。
- 错题分析与交互式 AI 导师出题也使用这个设置；课时阅读页保留原有的语言切换，不受影响（避免已缓存的讲解重新生成）。

### 其它

### 数据与版本

- 未新增 Dexie 表或索引，旧数据无需迁移；用户配置新增可选字段 `questionLanguage`。
- 出题提示词升至 `quiz-generator/v6`（v5 及更早保留）。

## V0.5.4 更新

本版修复用户反馈的测验问题：**题目数量不足**、**混合复习只从教材开头出题**、**题目出处显示“未找到对应的课程原文”**，并减少浏览器翻译扩展对界面的干扰。

### 测验题目数量

- **分批出题、自动补题**：每批最多 5 道题，每批给 AI 留足输出长度（以前沿用对话的默认上限 2048 token，题目一多回复会被截断）。某批题目不够（AI 少给或有题未通过格式校验）时，按缺少的题型再请求，最多补两轮；后续批次会告知已出过的题，避免重复。

- 出处没有记录原文摘录时，不再只显示“未找到对应的课程原文”：有对应片段就显示该片段原文，否则显示该页的课程原文，并注明“未记录具体原句”。只在显示时补充，不改动保存的数据。测验答题页、结果页和作业页同样生效。

### 数据与版本

- 分批、补题、题型对应、取材覆盖与出处补全均由单元 / 集成测试覆盖（模拟 AI 回复）。

## V0.5.3 更新

本版解决**大教材**的两处限制：上传不再有固定的 100 MB 上限，课程分析也不再只读教材开头，而是按章节读完整本书。

### 上传大小

- **取消固定的 100 MB 上限**：能否上传只看本机浏览器剩余的存储空间。空间不足时会提示“文件多大、还剩多少”，并建议删除不再需要的课程或文件；保存时恰好写满则提示“存储空间已满”，不会留下只存了一半的文件。
- **单个文件最大 2 GB**：这是浏览器一次能读入内存的大致上限，更大的文件可以按章节拆开上传（提示里也会这样说）。
- 一次最多选择 50 个文件的批量限制不变。

### 课程分析读完整本教材

- **以前**：课程分析每份教材只取前 200 个文本片段，合计再截到前约 5 万字（大约教材前几十页），后面的章节不会生成主题。
- **现在**：教材按章节切成若干部分（每部分约 4 万字，一章放不下时按小节、再按段拆），每部分单独请求 AI，同时进行两个，结果合并成一份。
- **合并规则**：同名的概念、公式、符号、例题、习题与先修知识会去重并保留各自的出处；同名主题若来自同一章被切开的两半就合成一个，来自不同章（如每章的“本章小结”）则后者改名为“本章小结 · Ch 2”。
- **失败处理**：任何一部分请求失败，整次分析算失败，原来保存的分析原样保留，不会存下只完成了一半的结果。
- **进度**：显示“正在请求 AI 提取知识（第 3/12 部分）”。
- **短教材不受影响**：一次装得下的课程仍只发一次请求，提示与以前逐字相同，已有分析不会被标记为过期。
- **以前只读了开头的大教材**：只有旧限制确实截断过的课程会被标记，分析面板提示“这份分析只读到了教材开头的一部分”，点“重新分析”即可读完整本；短课程不会被标记，也不会自动重跑。

### 其它改进

- **主题所属章节更准确**：优先采用 AI 标注、并经本地核对的来源段落所在章节，没有有效来源时才按文字重叠推断。
- **大教材不再卡顿**：按文字重叠推断章节时，每个段落只处理一次（以前在大教材上可能重复上百万次，页面会卡住数分钟）。
- **数据导出**：改为逐个文件拼接导出，大文件不再超出浏览器的字符串长度上限而导致导出失败；导出内容与以前完全相同。
- **存储统计**：设置页的存储占用改为累加文档记录里的大小，不再把所有原文件读进内存。

### 数据与版本

- 课程分析结果新增 `inputCoverage` / `inputParts` 两个可选字段；未新增 Dexie 表或索引，旧数据自动兼容。
- 提示词仍为 `document-analyzer/v2`（单次请求的提示不变；分段时在用户提示中加一段“第 i/n 部分”说明）。

### 验证

- `npm run lint`、`npm run typecheck`、`npm test`（**173 个测试文件 / 2180 项全部通过**）、`npm run build` 全部通过。
- 分段、合并、失败回滚、旧分析过期判断、存储空间检查与导出均由单元 / 集成测试覆盖（模拟 AI 回复与浏览器存储）。
- **未使用真实 AI 服务商复测长教材分析，也未在真实浏览器中上传超过 100 MB 的文件**；建议配置 API Key 后上传一本长教材试一次。

> 已知边界：长教材的 AI 调用次数随长度增加（约每 4 万字一次），费用与耗时相应增加；任一部分失败需整次重新分析，暂不支持只重试失败的部分；单个文件仍受浏览器 2 GB 读取上限约束。

## V0.5.0 更新

本版新增**医学科目**，以临床医学与口腔医学大一、大二的基础课为主（系统解剖、组织胚胎、生理、生化、药理基础、口腔解剖生理）：医学专用的科目说明与安全边界、医学考试常见的 X 型 / B 型 / 填空题、14 种本地计算的医学图，以及适合大量记忆的**复习卡片（间隔重复）**。和理科的图一样，AI 只提供讲解里的数值，计算全部在本地完成，算不对就不画。

### 医学科目

- **科目识别**：课程名含“系统解剖学”“组织学与胚胎学”“人体生理学”“病理”“药理”“口腔”“牙”等（及对应英文）时自动识别为医学；“医用化学 / 医用物理 / 医用高数”仍归化学 / 物理 / 微积分，“植物生理学”仍归生物。
- **科目说明**：中文术语与英文 / 拉丁术语并列、解剖学姿势与方位术语、FDI 牙位记录法、常用单位；名词解释 / 简答 / 论述的答题结构；常见错误（左右方位、神经支配混淆、单位换算等）。
- **安全边界（每次都附加）**：只做教学，不对真实个人做诊断、不给治疗或剂量建议，遇到个人健康问题建议就医；例题中的参考值与剂量仅为示意，以教材和临床指南为准。
- **医学单位**：`mmHg`、`bpm`、`mOsm/L`、`mEq/L` 等可直接带单位作答并自动换算；渗透压单位与 `mmol/L` 不互换。
- **符号键盘**：新增医学分组（↑↓、Na⁺ / K⁺ / Ca²⁺ / Cl⁻ / HCO₃⁻、O₂ / CO₂、pH、mmHg、mmol/L 等）。

### 新题型（全科可选）

- **X 型多选**：至少两个正确选项。**给部分分**：每选错一个抵消一个选对的（正确答案 ABC，选 AB 得 2/3，选 ABD 得 1/3）；只有全对才算“正确”，其余进入错题本。
- **B 型配伍**：一组共用的备选答案，为每个题干各选一个（同一答案可重复使用），每个题干单独计分。
- **填空题**：每个空可接受多种写法（如“乙酰胆碱”“ACh”“乙酰胆碱（ACh）”），忽略空格、全半角与标点；本地对不上时，若已配置 AI，会让 AI 只判断你的写法是否与答案**完全等价**（同义词 / 英文 / 缩写），得分仍在本地计算；AI 不可用时以本地结果为准。
- 结果页与错题本中的答案显示为选项字母（如 `ABD`、`1→B`、`(1) 乙酰胆碱`）。

### 医学图（本地计算）

- **生理**
  - **膜电位**：能斯特平衡电位 + GHK 静息电位，可拖动细胞外 K⁺ 浓度观察高钾 / 低钾的影响。
  - **动作电位**：神经细胞、心室肌细胞（0–4 期）、窦房结细胞，标注各期离子流。
  - **氧解离曲线**：可比较多条曲线（如正常与酸中毒的右移），给出血氧饱和度、血氧含量与动静脉血氧含量差。
  - **心室压力–容积环**：四个时期与瓣膜开闭点，每搏输出量、射血分数、心输出量与每搏功。
  - **肺容量**：肺量计曲线，由潮气量 / 补吸气量 / 补呼气量 / 残气量算出肺活量、深吸气量、功能残气量与肺总量。
  - **肾小球滤过与清除率**：有效滤过压各分力、清除率 C = U·V/P，有菊粉与 PAH 时给出滤过分数。
  - **酸碱平衡**：Davenport 图 + 国内病理生理教材的代偿公式（如代谢性酸中毒 PaCO₂ = 1.5 × HCO₃⁻ + 8 ± 2，呼吸性紊乱区分急性 / 慢性），超出代偿范围时提示合并紊乱；数值不符合 Henderson–Hasselbalch 方程时给出警告。
- **生化与药理**
  - **氨基酸**：净电荷随 pH 变化与等电点（如甘氨酸 5.97、赖氨酸 9.74）。
  - **糖代谢 ATP 计算**：逐步列出 ATP / NADH / FADH₂，可切换 P/O 比（现行 2.5 / 1.5 与旧教材 3 / 2）和穿梭方式（苹果酸–天冬氨酸 / α-磷酸甘油）。
  - **药代动力学**：一室模型（静注 / 口服）血药浓度–时间曲线、多次给药叠加与稳态，可调剂量与给药间隔，标出最低有效浓度与最低中毒浓度，给出清除率、AUC、平均稳态浓度、蓄积因子与达稳态时间（注明为教学模型，不构成用药建议）。
- **形态与口腔**
  - **牙位图**：FDI / Universal / Palmer 三种记录法互换，按临床习惯患者右侧显示在左。
  - **时间轴**：胚胎发育、牙萌出时间等，最多 4 条泳道。
  - **神经传导通路**：逐级神经元、从皮质到周围的分层与中线，标出交叉平面（如皮质脊髓束在延髓锥体交叉），可逐级显示。
  - **解剖对照表**：起止点、作用、神经支配等，可**一键加入复习卡片**。
- 医学课程同样优先显示**课程资料里的原图**；医学也可使用遗传、χ² 检验、回归与酶动力学图。

- 颜色定义集中在 `colorThemes.ts` + `globals.css`，**组件不硬编码颜色**。
- 主页使用克制的主题渐变；**导师阅读区保持纯色背景**，不影响长文可读性。
- **语义色优先**：成功 / 错误 / 警告 / 信息仍使用原有语义色，不会被主题覆盖。
- 切换主题是纯外观行为：**不触发 AI、不使课程分析 / 课时缓存 / 课程上下文失效**。

### 可访问性

- 新增 `--primary-strong`：**填色且承载文字**的表面（主按钮、徽章、Tooltip、品牌标记）改用对比度达标的色值，`--primary` 继续用于图标、链接、进度条、柔和状态与 focus ring。

| 配色               | 浅色主按钮 | 对比度              |
| ------------------ | ---------- | ------------------- |
| Pink Aqua          | `#1E8F9C`  | 3.84:1（原 3.24:1） |
| Warm Orange        | `#8C3332`  | 7.79:1（原 3.97:1） |
| Academic / Default | 原色已达标 | 4.82:1 / 15.55:1    |

- 新增对比度测试：从**真实 CSS 变量**解析并计算 8 个「明暗 × 配色」组合的 WCAG 对比度，正文类文字断言 ≥4.5:1。
- Pink Aqua 浅色主按钮仍为 **AA-large（3.84:1）**，未达 AA-normal —— 因为 `#1E8F9C` 是指定色值，达标需要改色。
- `#4C1A2` 不是合法 CSS hex：**逐字保留**在配色元数据中，**不写入任何 CSS 变量**，选择器把它渲染成「不可用」虚线色块，不伪造颜色。
- 已用**真实 Chromium** 验证：4 个视口（375 / 768 / 1024 / 1440）× 8 个组合**无横向溢出**；跟随系统模式下切换操作系统明暗时，配色主题保持不变。

- 每个内容块绑定 `chapterId / sectionId / chapterNumber / sectionTitle`，**不跨章合并**；页码随章节保留。
- 无法识别章节时不伪造目录，标记为「通用课程资料（低置信）」。
- Topic 会带上所属章节；Topic 页可按教材目录点选章节过滤主题。

### 阅读辅助与稳定性

- **划词提问（Ask AI / Explain）**：在课时页选中文字即可提问，携带选区与上下文，独立于翻译与交互导师。
- **原始视觉保留**：PDF 中的图、表、公式图片在 OCR 不可靠时保留原始图片/页面截图，不把错误 OCR 当正文。
- **`<think>` 推理隐藏**：模型返回的内部推理在进入渲染前被移除，含流式跨分片与未闭合情况。
- **课堂 / 学习 / 练习进度分离**，不合并成一个百分比。

### 导师：阅读与练习分离

- **课时页（Topic Tutor）与交互导师（Interactive Tutor）彻底分离**：课时页是**阅读材料**，一次生成、本地缓存、按语言分版，

- **并发去重**：同一课时的并发请求合并为一次 AI 调用（React StrictMode / 重挂载 / 快速切换主题都不会重复计费）

- **公式与符号面板**：从课时正文中**实际出现的 LaTeX** 提取符号并去重，不额外调用 AI；符号由 KaTeX 渲染，点击可复制
- **数学字符规范化**：新增数学上下文感知的归一化 —— 恢复 PDF 字体缺失 ToUnicode 时产生的 **Private Use Area** 字符

- **代码块与普通文本不受影响**：归一化只作用于真正的数学上下文，跳过 fenced/inline code
- **AI 提示词加固**：要求数学一律用 LaTeX，不得复制源文档中的损坏字符；语义优先于 glyph 外观
  （集合对称差用 `\triangle`，集合差用 `\setminus`）

### 阅读排版（交互导师）

- **AI 导师"导师不可用 / AI 没有返回可用的题目"**：根因是 `beginTopic()` 把"能否出题"当成了"能否开课"的前提。

  全部落空才回退到项目文档；主题描述也不再丢失
- **导师错误提示更准确**：区分"无法连接 / 响应超时 / 返回为空 / 主题没有课程内容 / 数据无法解析"，

- **PDF 异常字符排查**（`\uF0C8`、`\uF0C6`、`�`、`?` 等）：定位为 **pdf.js 对缺少 Unicode 映射的字体合成私用区码点**。
  新增检测与安全规范化：**保留原字符并明确告知用户**（文档上显示提示），**绝不猜测替换**；

- **测验题目出处**：`SourceReference` 增加 `chunkId`，出处引用必须来自**真实分块**；
  无法核实的内容会回退到真实原文，杜绝 AI 编造引用

### 界面

- **长文件名 / 长文本溢出统一处理**：文件名在界面上以省略号显示（保留扩展名），

- **数学与符号字体回退**：字体栈补充数学 / 符号字体，避免 `√ ∞ ∑ ∫ ∂ ≤ ≥ ≠ ≈ → ∈ ∪ ∩` 与希腊字母显示成方框

## 已知限制

- **需要自备 AI API**：不配置 API Key 时，AI 相关功能不可用（上传与本地处理仍可用）。
- **数据绑定浏览器**：清除站点数据 / 更换浏览器 / 更换访问地址，都会导致看不到原有数据。请使用同一地址，并定期用「数据管理 → 导出数据」备份；需要时用「从备份恢复」导回（完整替换，API 密钥需重新填写）。
- **数学等价判断有边界**：极复杂的表达式可能返回"无法自动判定"，此时该题不计入成绩，而不会算作答错。
- **OCR 质量取决于图片清晰度**：低置信度会给出提示。
- **课程分析为项目级**：一次分析覆盖该项目下所有已处理文档，生成的是课程级知识结构，而非逐文档结果。工作区中的章节级增量分析（Phase 7d，未发布）可只更新受影响的主题。
- **数学可视化范围受控**：只绘制白名单内的显式二维函数、二维向量、**2×2 线性变换**、**2×2 实矩阵的特征值/特征向量**、**2–3 集合的维恩图**与**最多 12 个节点**的小型图；隐式曲线（如 `x²+y²=r²`）、参数曲线、极坐标、分段函数、`tan`/`sec`/`csc`/`cot`、3D、向量场、几何证明图与动画均不支持，会安全回退为普通 LaTeX，不生成猜测图形。矩阵乘法、行列式、面积、集合区域、特征值与特征向量由本地确定性算法计算，AI 不提供坐标、变换结果、特征值或 determinant。**特征值可视化只支持 2×2 实矩阵的实特征值/特征向量**：复特征值、3×3 及更高维、Jordan 标准形均不绘制（复特征值安全回退，不投射到实平面）。3 个以上集合的维恩图、Euler 图自动布局也不支持。
