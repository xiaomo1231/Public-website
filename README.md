# AI 学习平台

> 面向理工科与医学大学生的**本地优先（Local-first）AI 学习平台**

把你自己的课程资料（PDF、Word、PPT、图片）导入进来，由你自己配置的 AI 把它整理成结构化知识，
再通过问答式 AI 导师、自适应测验和错题本来学习。

课程资料与学习数据默认保存在本机浏览器中；AI 服务由你自行配置。

## 项目简介

这是一个**给自己用的**大学课程学习工具，尤其适合数学、物理、化学、生物、计算机、统计等理工科课程，以及临床医学与口腔医学大一大二的基础课（解剖、组织胚胎、生理、生化、药理基础、口腔解剖生理）。

它解决的核心问题是：**课程资料很多，但没人陪你把它们真正弄懂。**

传统做法是"看 PDF → 看不懂 → 放弃"。这个项目把流程变成：

```text
导入课程资料
    ↓
AI 提取结构化知识（主题 / 概念 / 公式 / 符号 / 例题 / 习题）
    ↓
AI 导师用提问的方式带你学（不是直接把答案倒给你）
    ↓
做测验 → 错题自动进错题本 → AI 分析你错在哪 → 针对性再练
```

几个设计上的取舍：

- **本地优先**：课程文件、学习记录、错题本都在你自己的浏览器里，不上传到任何服务器。
- **自带 AI**：项目不提供 AI 服务，你自己填 API Key。用哪家、用哪个模型由你决定。
- **本地解析**：PDF 解析、OCR、分块全部在浏览器本地完成，只有"分析"和"提问"才会调用 AI。
- **不评判你**：错题分析只陈述可观察到的模式（如"符号处理"、"概念理解"），**永远不会**给你贴"粗心"这种标签。

## 核心功能

### 课程资料管理

- 支持格式：**PDF、DOCX、PPTX、图片（PNG / JPG / WebP / GIF / BMP）、粘贴文本**
- **批量上传**：一次可选多个文件，每个文件生成一份独立文档（最多 50 个/批，并发处理 2 个）
- 上传后自动在**本地**完成：文本提取 → 结构识别 → 语义分块
- 图片走**本地 OCR**（tesseract.js），不联网
- 每个分块都保留来源引用，例如 `Calculus.pdf · Page 12 · § 导数`
- 重复文件会被识别并跳过，不会静默创建重复文档

### AI 课程分析

- 一次性提取：**主题、概念、公式、符号、例题、习题、先修知识**
- 符号会记录"上下文"，因此同一个符号在不同主题下可以有不同的含义
- 采用**流式请求**，长课程分析不会因为固定超时而中断
- 分析失败时会明确告诉你原因（如"输出被截断"、"API 密钥无效"），并保留已提取的文档与文本

### AI 导师（AI Tutor）

问答式学习，而不是直接给答案：

```text
简短讲解 → 提问 → 你作答 → 评价 → 反馈 → 渐进提示 → 下一题
```

- 回答基于你的课程资料；超出资料范围的内容会明确标注为"补充说明"
- 提供**渐进提示**（逐步给，不直接给答案）
- 每次会话都保存在本地，可在"对话记录"里回看
- 化学 / 生物讲解会配图：课程资料里的原图优先显示；此外可由本地计算画出**分子结构式、反应能量图、滴定曲线、遗传棋盘格、系谱图、转录与翻译（中心法则）**——AI 只提供课时中的事实，分子式、ΔH / Eₐ、每个 pH、配子与比例、代数分层、氨基酸序列都在本地计算，算不对的图会被丢弃而不是画错
- 按大学深度：滴定支持**多元酸**（如磷酸，三个计量点）和**弱碱**；遗传支持**伴性遗传**（儿子 / 女儿分开给比例）、**复等位基因与共显性**（ABO 血型）；系谱图会自动分析**可能的遗传方式**（常 / X 连锁、显 / 隐性、Y 连锁）并说明排除理由；转录翻译区分**链的书写方向**、从**起始密码子 AUG** 开始；统计支持 **t / χ² / F 分布**与**卡方拟合优度检验**（χ²、自由度、p 值、结论）
- **其它理科也有可交互的图**（同样由本地计算，AI 只提供讲解里的公式和数据）：
  - **公式探索器**（所有理科）：讲解里的公式配上参数滑块，拖动即可看到曲线如何变化，虚线保留原曲线，可一键还原
  - **微积分**：切线与导数（可拖动切点、割线逼近）、黎曼和（左 / 右 / 中点 / 梯形，分段数可调，与定积分比较误差）、泰勒多项式（阶数 0–10 逐级逼近）
  - **物理**：受力分析（合力、是否平衡、加速度，可画斜面）、运动图像（x-t / v-t / a-t 联动，含位移与路程）、透镜 / 面镜光路图（可拖动物距，判断实像虚像、正立倒立、放大缩小）、串并联电路（等效电阻及各电阻电压、电流、功率）
  - **统计**：回归直线（R²、斜率检验、置信带与预测带）、均值的置信区间（z / t，可调置信水平）
  - **化学**：反应动力学（0 / 1 / 2 级，半衰期与线性化图）、阿伦尼乌斯图（由数据拟合活化能）
  - **生物**：酶动力学（米氏曲线与双倒数图，四种抑制类型）、种群增长（指数 / 逻辑斯谛，拐点与最大增长速率）
  - **计算机**：排序算法逐步回放（冒泡 / 插入 / 选择 / 归并 / 快排）、二叉搜索树（逐个插入、四种遍历）
- 化学、生物、概率统计的科目说明已按大学深度改写（热力学 / 动力学 / 有机反应机理；链极性、伴性遗传、χ² 检验、哈代-温伯格；t / χ² / F 检验的前提与自由度等）
- **医学（临床 / 口腔）**也有本地计算的图：
  - **生理**：膜电位（能斯特 / GHK，可拖动细胞外 K⁺ 浓度）、动作电位（神经 / 心室肌 / 窦房结分期）、氧解离曲线（右移因素、血氧含量）、心室压力–容积环（每搏输出量、射血分数、心输出量）、肺容量（肺量计曲线）、肾小球滤过与清除率、酸碱平衡（Davenport 图，按国内病理生理教材的代偿公式判断是否合并其它紊乱）
  - **生化与药理**：氨基酸带电与等电点、糖代谢 ATP 计算（可切换 P/O 比与穿梭方式）、药代动力学（一室模型血药浓度曲线、多次给药与稳态，可调剂量与间隔）
  - **形态与口腔**：牙位图（FDI / Universal / Palmer 互换）、胚胎发育 / 牙萌出时间轴、神经传导通路（逐级神经元与交叉平面）、解剖对照表（起止点、神经支配等，可一键加入复习卡片）
  - 医学讲解会遵守安全边界：只做教学，不对真实个人做诊断、不给治疗或剂量建议；例题中的参考值与剂量仅为示意

### 公式与符号

- 从课程资料中提取的**公式**（KaTeX 渲染）与**符号**集中展示
- 支持搜索，点击即可复制
- 同一个符号的不同含义会作为独立条目保留

### 划词翻译

- 在页面中**选中任意文字**即可弹出翻译
- 会带上上下文段落，让翻译更准确
- 翻译目标语言跟随你的设置（中文 / 英文）

### 测验（Quiz）

- 从课程分析结果生成题目，**题目有据可依**（来自你的资料）
- 题型见下方"支持的测验题型"
- 支持：主题选择、题目数量、起始难度、题型组合
- 答题后可查看解析、参考答案与"再来一组"（同主题 / 相似 / 更难 / 更简单 / 薄弱点强化）

### 错题本

- 答错的题目**自动收集**，同一道题多次答错会合并
- 由 AI 分析：**从哪一步开始偏、关键错误是什么、为什么这一步不成立、正确思路**
- 错题可标记为"已掌握"或归档
- 提供**薄弱点提示**（"可能需要复习的部分"）

### 复习卡片（间隔重复）

- 适合需要大量记忆的课程（解剖、组织学、名词解释）：从课程概念一键生成（名词 → 解释），在讲解里的解剖对照表上一键加入，也可以自己写
- 复习时先看正面、回想后翻面，按“忘了 / 困难 / 记得 / 简单”评分，系统据此安排下次复习时间（10 分钟到数月不等）；键盘空格翻面、1–4 评分
- 与课程概念关联的卡片，复习结果会以较低权重计入掌握度
- 完全本地，不调用 AI

### 自适应练习与掌握度

- 难度根据近期正确率、连对/连错、知识点掌握度动态调整
- 掌握度是**基于练习记录的估计值**，不是对能力的绝对测量
- 提供知识点维度的掌握度视图（最薄弱的排在前面）

### 本地优先数据存储

- 所有数据存于浏览器 **IndexedDB**（Dexie，39 张表，schema v15）
- 课程原始文件字节同样保存在本地
- 无需后端、无需注册账号、无遥测
- 首次启动会预置两个演示邀请码（见下方"首次使用"）

## 支持的测验题型

| 题型 | 说明 |
| --- | --- |
| **单项选择题** | 4 个选项，选择一个 |
| **判断题** | 正确 / 错误 |
| **数值题** | 输入数值，按容差比较 |
| **数学表达式题** | 输入表达式，按数学等价判断（如 `x^2/2` 与 `0.5x^2` 视为等价） |
| **简答题** | 用自己的话作答，按**得分点**计分：每道题有 2–6 个得分点，答到几个得几个（例如 3/5 = 60%）。AI 逐点核对，答到的点会引用你写的原话作为依据；不同意判定可以申诉，申诉后不计分 |
| **代码输出题** | 计算机科目：写出程序的确切输出，逐字符判分 |
| **化学方程式题** | 化学科目：写出（配平的）化学方程式，如 `2H2 + O2 -> 2H2O`、`Fe^3+`、半反应 `MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O`、有机结构式 `CH2=CH2 + H2 -> CH3CH3`。本地检查物质是否齐全、原子与电荷是否守恒，并指出缺了什么或哪里没配平；有机物结构写法与参考答案不同（可能是同分异构体）时不判对错，提示你对照参考答案 |
| **排序题** | 把步骤 / 过程按正确顺序排列（拖拽或上下按钮）。按“最长已排对的顺序”给部分分，例如 4 步中只有一步放错得 3/4 |
| **X 型多选题** | 选出所有正确选项（至少两个正确）。给部分分：每选错一个抵消一个选对的，例如正确答案 ABC，选 AB 得 2/3，选 ABD 得 1/3 |
| **B 型配伍题** | 一组共用的备选答案，为每个题干各选一个（同一答案可重复使用），每个题干单独计分 |
| **填空题** | 每个空可接受多种写法（如“乙酰胆碱”“ACh”“乙酰胆碱（ACh）”），忽略空格、全半角与标点；本地对不上时，若已配置 AI，会让 AI 只判断你的写法是否与答案完全等价（同义词 / 英文 / 缩写），得分仍在本地计算 |

> **说明：简答题需要连接 AI 才能判分。** 没有配置 AI 时，简答题会显示得分点和参考答案，但不计入成绩。
> 教授练习题和 AI 导师里的简答题也按同样的得分点方式判分，并计入错题本与掌握度。
>
> 带单位的数值题支持大学常用单位：`mol/L`、`M`、`mM`、`µM`、`kJ/mol`、`kcal/mol`、`J/(mol·K)`、`atm`、`Torr`、`kDa`、`ppm`、`Å`、`eV` 等，以及医学常用的 `mmHg`、`bpm`、`mOsm/L`、`mEq/L`，任意同量纲单位先换算再比较（渗透压单位与 `mmol/L` 不互换）。

数学等价判断使用 `mathjs`：先尝试符号化简，再用数值采样验证，因此**不依赖 AI 判分**，
结果可复现。无法确定时会明确显示"无法自动判定"，而不是猜测对错。

## AI 配置

**本项目不提供 AI 服务，也不会内置任何 API Key。** 你需要配置自己的 AI API。

启动后进入：

```text
设置 → AI 设置
```

填写：

| 项 | 说明 |
| --- | --- |
| AI 服务商 | 选择预设或"自定义（OpenAI 兼容）" |
| API Base URL | 服务商接口地址 |
| API Key | 你自己的密钥 |
| 模型 | 模型名称 |
| 温度 / 最大 Token 数 | 采样参数 |

内置预设（均为 **OpenAI 兼容接口**）：

```text
OpenAI
Qwen（DashScope）
DeepSeek
MiniMax
MiMo
自定义（任意 OpenAI 兼容端点）
```

配置完成后可点「测试连接」验证。API Key 会以 **AES-GCM 加密**保存在本地（密钥为不可导出的设备密钥），
不会写入日志、不会放进 URL、不会提交到本仓库。

> 也可以直接改用任何兼容 `/chat/completions` 的服务。

## 安装与运行

### 环境要求

- **Node.js 20 或更高版本**（写在 `package.json` 的 `engines` 中）
- 现代浏览器（Chrome / Edge / Firefox / Safari）

### 快速启动（推荐）

项目自带启动器，会替你检查运行环境。

**Windows**：双击项目根目录下的 **`Start.bat`**

**macOS / Linux**：

```bash
./launcher/unix.sh
```

启动器的流程：

```text
1. 检测 Node.js 是否存在、版本是否满足要求
2. 检测 npm 是否可用
3. 缺少或版本过低 → 提示 → 等你确认 → 才尝试安装
4. 安装完成后重新检测
5. 检查依赖是否完整（必要时安装）
6. 启动开发服务器并打开浏览器
```

已经装好 Node.js 的用户**不会被重复安装**，启动器会直接进入启动流程。

> **关于安装 Node.js**：启动器不会静默安装，也不会绕过系统权限。
> Windows 使用 `winget`；macOS 使用 Homebrew；Linux 按发行版使用 `apt` / `dnf` / `pacman` / `zypper`。
> 如果这些工具不存在，启动器会给出 [Node.js 官方下载页面](https://nodejs.org/zh-cn/download)，由你手动安装。
>
> 详见 [launcher/README.md](launcher/README.md)

### 手动启动

不想用启动器，或本机已有符合要求的 Node.js：

```bash
git clone <仓库地址>
cd website
npm install
npm run dev
```

然后打开 **http://localhost:5173**

> **重要**：应用数据（项目、文档、AI 配置）保存在浏览器的 IndexedDB 中，而 IndexedDB 是**按来源（origin）隔离**的。
> 请始终使用**同一个地址**（`http://localhost:5173`）。
> 不要使用 Vite 打印的 `Network` 地址，也不要让端口变成 5174/5175 —— 那会被浏览器视为另一个网站，
> 你会看到一个"空的工作区"。项目已固定端口（`strictPort`）以避免这个问题。

### 首次使用

首次启动会预置两个演示邀请码：

| 邀请码 |
| --- |
| `WELCOME-LEARN` |
| `STUDENT-2026` |

邀请码**仅在本地校验**，它是一个本地应用的访问门，不是账号系统。

### 生产构建

```bash
npm run build     # 输出到 dist/
npm run preview   # 本地预览构建结果
```

## 使用流程

```text
1. 创建项目（选择科目，如"微积分"）
2. 在「文档」标签页上传课程资料（可批量）
3. 等待本地处理完成（提取 → 分块）
4. 到「课程分析」标签页点击「分析课程」
5. 去「AI 导师」按主题学习，或去「测验」做题
6. 做错的题自动进「错题本」，可分析、可重练
7. 在「掌握度」里看知识点的强弱分布
```

在配置 AI 之前，上传与本地处理都可以正常使用；只有分析、导师、测验生成等需要 AI。

## 数据与隐私

- 本项目采用 **Local-first** 设计：课程文件、分块、学习记录、错题本、AI 设置都保存在**本机浏览器**中。
- 本仓库**不包含**任何用户课程资料、个人 API Key 或学习数据。
- PDF 解析、OCR、分块等处理**在本地完成**，不联网。
- 当你配置了 AI API 后，**相关内容会发送给你所配置的 AI 服务商**：
  - 课程分析：会发送用于分析的分块文本
  - 导师提问 / 测验生成：会发送相关片段与你的作答
  - 划词翻译：会发送选中的文本与上下文段落
  - 请求**只包含完成任务所必需的内容**，不会发送你的整个文档库
- 数据是否被服务商留存、如何使用，**取决于你所选择的 AI 服务商及其政策**，本项目无法控制。
- API Key 以 **AES-GCM** 加密存储，密钥为不可导出的设备密钥。
- **联网参考图片（默认关闭）**：在「设置 → 联网参考图片」开启后，化学 / 生物 / 医学讲解页会出现「查找参考图片」按钮（医学优先查找公有领域的格氏解剖学图版和 CC 授权的组织切片图，从不检索患者照片）。点击时会把**主题的搜索词**（如化合物名称、“线粒体结构图”、“Gray brachial plexus”）发送给 **PubChem** 和 **Wikimedia Commons**，不会发送你的课程资料。图片保存在本机，并注明来源、许可协议和作者；只采用允许再使用的许可（公有领域、CC0、CC BY、CC BY-SA）。可选“用 AI 模型核对每张图片”，此时图片会发送给你配置的 AI 服务商。

> 换句话说：**在你不使用 AI 功能时，数据不离开本机；一旦调用 AI，相关片段会发送到你自己配置的服务商。**

## V0.4.0 更新

本版把理科各科适配到**大学课程深度**：修正了化学 / 生物在大学题目里会出错的地方，补齐大学常用单位与科目说明，并为物理、微积分、统计、化学、生物、计算机新增一批**可交互的本地计算图**。所有图都由 AI 只提供讲解里的公式和数据，数值一律在本地计算，算不对就不画，不会画错。

### 正确性修复

- **转录与翻译**：区分链的书写方向（默认按大学惯例 5′→3′，序列自带 5′/3′ 标注时以标注为准），模板链按 5′→3′ 书写时先反向对齐；默认从第一个起始密码子 AUG 开始翻译，前面显示为 5′ 非翻译区。
- **有机方程式**：支持结构式中的双键 / 三键 / 单键（`CH2=CH2`、`HC≡CH`、`CH3-CH3`），没有其它箭头时自动挑出能配平的那个 `=` 作为反应箭头。
- **同分异构体**：分子式相同但结构写法与参考答案不同（如乙醇与二甲醚）时不判对错，提示对照参考答案，不计分。
- **单位**：新增 `M` / `mM` / `µM`、`Da` / `kDa`、`cal` / `kcal`、`ppm`、`Å`（独立的计算实例，不影响数学表达式判分）。

### 科目说明按大学深度改写

- **化学**：有机结构式与系统命名、ΔG° = ΔH° − TΔS° = −RT ln K、速率方程与阿伦尼乌斯、酸碱平衡与近似条件、有机反应机理与立体化学。
- **生物**：核酸链极性、伴性遗传与复等位基因、χ² 检验、系谱判断、哈代-温伯格平衡、米氏方程。
- **概率统计**：t / χ² / F 检验的前提与自由度、估计方法、回归与方差分析。
- **物理**：微积分形式的力学、电磁学（高斯 / 安培定律）、基尔霍夫定律、热力学第一 / 第二定律。
- **计算机**：递推式与主定理、循环不变式、稳定性与原地排序。
- 各理科都要求讲解中写明可以画图的数据（力、浓度、数组、基因型等）。

### 化学 / 生物 / 统计：更深入的图

- **分布**：新增 t、χ²、F 分布（与查表值核对）；在 0 处无界的密度曲线正确裁切；不存在的矩显示“不存在”。
- **卡方拟合优度检验**（新）：观测值与期望比例对照，给出 χ²、自由度、p 值、临界值与结论（孟德尔豌豆数据 χ² = 0.47，p = 0.925）。
- **遗传**：伴性遗传（儿子 / 女儿分开给比例）、复等位与共显性（ABO 血型显示为 A / B / AB / O）、常染色体与 X 连锁双基因杂交。
- **系谱遗传方式分析**（新）：逐一判断常染色体显 / 隐性、X 连锁显 / 隐性、Y 连锁是否可能，并写出排除理由与涉及成员（假设完全外显、无新发突变）。
- **滴定**：多元酸（如磷酸三个计量点）与弱碱（用强酸滴定）；只有在 pH 与 pKₐ 确实接近时才标“pH ≈ pKₐ”。

### 其它理科：可交互的图（新）

- **公式探索器**（所有理科）：讲解里的公式配上参数滑块，拖动即可看到曲线变化，虚线保留原曲线，可一键还原。
- **微积分**：切线与导数（符号求导，可拖动切点、割线逼近）、黎曼和（左 / 右 / 中点 / 梯形，与定积分比较误差）、泰勒多项式（0–10 阶逐级逼近）。
- **物理**：受力分析（合力、平衡、加速度，可画斜面）、运动图像（x-t / v-t / a-t 联动与时间游标，位移与路程分开计算）、透镜 / 面镜光路图（可拖动物距，判断实虚、正倒、放大缩小）、串并联电路（等效电阻与各电阻电压、电流、功率）。
- **统计**：回归直线（R²、斜率 t 检验、置信带与预测带）、均值置信区间（z / t，可调置信水平）。
- **化学**：0 / 1 / 2 级反应动力学（半衰期与线性化图）、阿伦尼乌斯图（由数据拟合活化能）。
- **生物**：酶动力学（米氏曲线与双倒数图，四种抑制类型）、种群增长（指数 / 逻辑斯谛，拐点与最大增长速率）。
- **计算机**：排序算法逐步回放（冒泡 / 插入 / 选择 / 归并 / 快排，比较与写入计数）、二叉搜索树（逐个插入、四种遍历与树高）。
- 各图族只发送给对应科目，避免不相关的提示词开销；公式安全解析（白名单校验，不执行任意代码）。

### 数据与版本

- 可视化数据结构升至 **schema v9**，提示词升至 `visualization-generator/v9`（旧版本保留，旧数据照常显示）。
- 科目画像修订：化学 r3、生物 r2、概率统计 r2、物理 r2、微积分 r2、计算机 r2——这些科目已缓存的讲解与分析会**重新生成一次**；其它科目不受影响。
- 未新增 Dexie 表或索引。

### 验证

- `npm run lint`、`npm run typecheck`、`npm test`（**168 个测试文件 / 2088 项全部通过**）、`npm run build` 全部通过。
- 全部新图已在真实浏览器中逐一检查（桌面、深色模式、375px 手机宽度，无横向溢出），数值与标准算例核对一致；浏览器检查中发现并修复了镜面弯曲方向、切线式符号、积分式括号、浮点噪声、电路标签截断等问题。
- **未使用真实 AI 服务商生成讲解复测**；建议配置 API Key 后在各科各试一个主题。

> 已知边界：滴定支持至多三元酸 + 强碱、一元弱碱 + 强酸（不含活度校正）；棋盘格最多两对基因、至多一个 X 连锁基因，不含连锁交换与上位效应；同分异构体只能提示、不能自动判定；电路仅支持串并联电阻网络；不绘制 3D 结构、反应机理与细胞 / 器官示意图。

## V0.2.9 更新

本版新增**作业讲解（Homework Walkthrough）**：把老师布置的作业文档变成可逐步学习的题目，并在重新识别时**保护学生已经写下的内容**。

### 作业讲解

- **从作业文档生成题目**：上传标为作业的文档后，AI 从真实分块中提取题目，每道题都绑定来源引用（来自真实分块），并预生成**渐进提示**与**完整解法**（默认隐藏，按需展开）。
- **以学生为中心**：每道题独立保存**草稿、已展开的提示进度、答案展开状态与提问对话**，刷新后自动恢复；就地提问由 AI 以引导式（不直接给答案）方式回答。
- **内容三态标注**：区分文档内容 / AI 补充说明 / AI 生成练习，来源引用只指向真实分块。
- **进度与入口**：课程模块导航新增「作业讲解」；作业主页列出所有作业，点开进入逐题讲解，支持题号导航与上一题 / 下一题。

### 重新识别、归档与恢复

- **整份重新识别**：可对已生成的作业再次识别；匹配按**内容**（题目文本 + 来源分块）进行，题目顺序变化也能对应回原题。
- **归档而非删除**：本次未匹配到的题目进入**归档区**（保留草稿、提示、解法与对话），可查看、**恢复**或显式删除。
- **再次出现即恢复**：已归档题目在后续重新识别中再次出现时，若匹配**可靠且唯一**，会**复用原题 ID 并恢复全部学习记录**，而不是新建空白题；歧义时**不猜测**，保留旧记录。
- **原子提交**：匹配、恢复、归档与新增在**单个事务**内完成；AI 或校验失败时，原题目与学生记录保持提交前状态。
- **单题重生成**：可就地重新生成某题的提示与解法；学生草稿与对话保留，提示数量减少时安全收敛可展示的进度。

### 数据与安全

- **内容指纹 `sourceHash`**：由参与分析的 chunk **内容**（文本 / 顺序 / 页码 / 章节）计算，**不含 `processedAt`、不含 chunk id**。因此「原样重新处理」不会误判为内容变化，只有文本真的变了才算变。
- **四个版本概念分离**：Dexie 结构版本 / `promptVersion` / 分析结果形状 `schemaVersion` / 教材结构 `version` + `structureHash`。不再合并成一个字段。
- **新鲜度判定**（纯函数）：`sourceHash`、`promptVersion`、`schemaVersion`、结构指纹（优先 `structureHash`，旧数据回退 `version`）、`status`。**明暗模式、配色主题、界面语言、课堂进度、练习记录都不参与。**
- **原子替换**：重新分析改为单事务写入 —— 要么新结果完整落库，要么旧结果原样保留。**AI 失败时旧分析不受影响。**
- **上传后自动分析**：处理流程结束后按需触发一次，并做并发去重（同一项目同时只发一次请求）。**打开任何页面都不会触发分析。**
- **未配置 API Key 是 `no-provider`**，不是「分析失败」。
- 修复 `promptVersion` 被硬编码为 `v1` 的问题；修复用户资料并发写入时的丢更新。
- **增量分析在 V0.2.5 只到规划层**：`AnalysisScope`、`detectAffectedStructure`、`planIncrementalUpdate`、`planContentDependencies` 已就绪并有测试，但**真正的章节级增量生成尚未实现**；按章节请求会被明确拒绝（`ANALYSIS_SCOPE_UNSUPPORTED`），不会静默跑全项目。原因：Topic 可以跨章节，贸然按章节删除重建会破坏 Topic / 笔记 / 文字稿 / 练习题的既有绑定。**章节级增量生成已在工作区实现（Phase 7d，未发布），见上方“工作区”说明。**

### 配色主题（Color Themes）

新增 3 套配色，与明暗模式是**两个独立维度**（`Light/Dark/System` 决定明暗，`Color Theme` 决定色系）：

## 已知限制

- **需要自备 AI API**：不配置 API Key 时，AI 相关功能不可用（上传与本地处理仍可用）。
- **数据绑定浏览器**：清除站点数据 / 更换浏览器 / 更换访问地址，都会导致看不到原有数据。请使用同一地址，并定期用「数据管理 → 导出数据」备份。
- **数学等价判断有边界**：极复杂的表达式可能返回"无法自动判定"，此时该题不计入成绩，而不会算作答错。
- **OCR 质量取决于图片清晰度**：低置信度会给出提示。
- **课程分析为项目级**：一次分析覆盖该项目下所有已处理文档，生成的是课程级知识结构，而非逐文档结果。工作区中的章节级增量分析（Phase 7d，未发布）可只更新受影响的主题。
- **数学可视化范围受控**：只绘制白名单内的显式二维函数、二维向量、**2×2 线性变换**、**2×2 实矩阵的特征值/特征向量**、**2–3 集合的维恩图**与**最多 12 个节点**的小型图；隐式曲线（如 `x²+y²=r²`）、参数曲线、极坐标、分段函数、`tan`/`sec`/`csc`/`cot`、3D、向量场、几何证明图与动画均不支持，会安全回退为普通 LaTeX，不生成猜测图形。矩阵乘法、行列式、面积、集合区域、特征值与特征向量由本地确定性算法计算，AI 不提供坐标、变换结果、特征值或 determinant。**特征值可视化只支持 2×2 实矩阵的实特征值/特征向量**：复特征值、3×3 及更高维、Jordan 标准形均不绘制（复特征值安全回退，不投射到实平面）。3 个以上集合的维恩图、Euler 图自动布局也不支持。
